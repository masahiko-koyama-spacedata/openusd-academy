LESSON 24B

uniform

Faceごとに一つの値を使うInterpolation

今日これだけ: 値数はFace数

公式情報に基づく説明

公式: uniformは各Faceまたはcurveごとに一値を対応させます。

Point数ではなくFace数を数えます。

目的とDiagram

USDA

int[] faceVertexCounts = [4, 4]
color3f[] primvars:displayColor = [(1, 0, 0), (0, 0, 1)] (
    interpolation = "uniform"
)

Faceが2枚なので色も2値です。

Python

pv.SetInterpolation(UsdGeom.Tokens.uniform)
pv.Set([red, blue])

USDA → Python

"uniform" → Tokens.uniform

例題

6 FaceのCubeに必要な値数は？ 6です。

よくある間違い

原因: 英単語から「全体で同じ」と推測する。
解決策: PrimvarのuniformはFaceごとに一値です。
