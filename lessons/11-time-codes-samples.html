Time Codeと
Time Sample

時点と値の組で変化を記述します

今日これだけ

Time Codeは時点 Time Sampleはその時点のAttribute値

公式情報に基づく説明

時点と値を分ける

Time Codeは単位を持たない時間上の位置です。Time SampleはTime CodeとAttribute値の組です。StageのtimeCodesPerSecondがTime Codeを秒へ対応させます。

OpenUSD Academy Note

Time Codeを目盛り、Time Sampleを目盛りに置いた値として読みます。

USDA

radiusを二つの時点に書く

time-samples.usdaUSDA
#usda 1.0
(
    startTimeCode = 1
    endTimeCode = 24
    timeCodesPerSecond = 24
)

def Sphere "Ball"
{
    double radius.timeSamples = {
        1: 1,
        24: 2,
    }
}

先頭の丸括弧はLayer Metadataです。1: 1はTime Code 1に値1、カンマは項目の区切りです。波括弧内に時点と値の組を書きます。

Diagram

時間軸に値を置く

Python

Attributeへ時点ごとの値を設定する

create_samples.pyPython
from pxr import Usd, UsdGeom

stage = Usd.Stage.CreateNew("time-samples.usda")
stage.SetStartTimeCode(1)
stage.SetEndTimeCode(24)
stage.SetTimeCodesPerSecond(24)
ball = UsdGeom.Sphere.Define(stage, "/Ball")
radius = ball.GetRadiusAttr()
radius.Set(1, Usd.TimeCode(1))
radius.Set(2, Usd.TimeCode(24))
stage.Save()

Setの最初の引数が値、次がTime Codeです。丸括弧は入力、カンマは値と時点の区切りです。

USDA → Python mapping

時点と値を対応させる

  1. USDA

    startTimeCode = 1↓

    Python

    stage.SetStartTimeCode(1)

  2. USDA

    1: 1↓

    Python

    radius.Set(1, Usd.TimeCode(1))

Beginner notes

フレーム番号と決めつけない

OpenUSD Academy Note

Time Code自体は単位を持ちません。USDAのコロンは時点と値、Pythonのカンマは引数を区切ります。インデントは所属、引用符は名前、スラッシュはPathです。

Common mistakes

値と時点の順を確認する

Pythonの引数を逆にする

原因: USDAの時点: 値とPythonのSet(値, 時点)は順が違います。

解決策: 対応表で確認します。

MetadataへTime Sampleを書く

原因: Metadataは時間サンプルを持ちません。

解決策: Attributeへ設定します。
