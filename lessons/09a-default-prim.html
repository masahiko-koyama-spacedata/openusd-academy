Default Prim

Layerを外から利用するときの入口となるtop-level Primを指定する

今日これだけ

Default PrimはLayerの代表となるtop-level Prim

ReferenceやPayloadでPrim Pathを省略したとき、どのPrimから内容を取り込むかをLayer Metadataで伝えます。

公式情報に基づく説明

Stageの入口を一つ決める

公式: defaultPrimはLayer Metadataです。そのLayerのtop-level Primを主な入口として指定します。root LayerをReferenceまたはPayloadで利用するとき、利用側は対象Prim Pathを省略できます。

公式: Default PrimにはStage上のtop-level Primを設定します。

OpenUSD Academy Note

ファイルの中身を全部まとめる命令ではありません。「このファイルを代表して外へ見せるPrimはこれ」と書く案内札です。

Diagram

Layer Metadataから入口Primへ進む

USDA

Default Primを記述する

asset.usdaUSDA
#usda 1.0
(
    defaultPrim = "Chair"
)

def Xform "Chair" {
    def Cube "Seat" {
        double size = 1
    }
}

def Xform "Lamp" {
}

#usda 1.0はヘッダーです。丸括弧( )はLayer Metadataの範囲、=は左の項目へ右の値を設定する記号です。二重引用符" "は名前の範囲、波括弧{ }はPrimの内容を示します。インデントは所属を読みやすくします。

一行ずつ読む

defaultPrim = "Chair"を分解する

  1. defaultPrim

    Layerの入口名を保持するMetadataのキーです。

  2. =

    左側のMetadataへ右側の値を設定します。

  3. "Chair"

    入口にするtop-level Primの名前です。先頭に/は付けません。

  4. def Xform "Chair"

    Stage上に/Chairを定義します。Metadataの名前とPrim名が一致します。

結果

Chairだけが入口になる

/Chairと/Lampはどちらもtop-level Primですが、Default Primは/Chairです。Prim Pathを省略した外部ReferenceやPayloadは/Chairを対象にします。/Lampまで自動で含める設定ではありません。

Python

Stage APIで設定して確認する

create_asset.pyPython
from pxr import Usd, UsdGeom

stage = Usd.Stage.CreateNew("asset.usda")
chair = UsdGeom.Xform.Define(stage, "/Chair")
UsdGeom.Cube.Define(stage, "/Chair/Seat")
UsdGeom.Xform.Define(stage, "/Lamp")

stage.SetDefaultPrim(chair.GetPrim())
print(stage.GetDefaultPrim().GetPath())
stage.Save()

.は左のオブジェクトが持つ機能へ進む記号、丸括弧は関数へ値を渡す記号です。"/Chair"の先頭のスラッシュは絶対Prim Pathを示します。この例はtop-levelで実行するため、Pythonの行を字下げしません。

USDA → Python mapping

同じ設定を対応させる

  2. USDA

  3. 確認

    結果は/Chairです。

例題

どのPrimが取り込まれるか

問題: /Chairと/Lampがあり、defaultPrim = "Chair"です。Prim Pathを省略してこのLayerをReferenceしました。入口はどれですか。

答え: /Chairです。/Lampを対象にする場合はReference側で</Lamp>を明示します。

OpenUSD Academy Note

Default Valueとは別の言葉

OpenUSD Academy Note

Default PrimはStageの入口となるPrimです。AttributeのDefault Valueは時間に依存しない値です。役割は異なります。

よくある間違い

名前とPathと階層を混同しない

defaultPrim = "/Chair"と書く

原因: Metadataの値をPrim Pathだと考えています。

解決策: top-level Primの名前をdefaultPrim = "Chair"と書きます。

子PrimをDefault Primにする

原因: 好きなPrim Pathを入口にできると考えています。

解決策: Default Primにはtop-level Primを設定します。子Primを使うならComposition ArcでPathを明示します。

未設定でもファイル全体が取り込まれると思う

原因: Prim Path省略時の入口解決を見落としています。

解決策: Default Primを設定するか、利用側で対象Prim Pathを明示します。

Glossary

このページで出た言葉

Default Prim
Layer Metadataで指定する、Layerの主な入口となるtop-level Prim。
top-level Prim
擬似ルート直下にあり、Pathが一要素のPrim。
Layer Metadata
個々のPrimではなくLayer全体について記述する情報。
Default Value
時間に依存しないAttribute値。Default Primとは別の概念。
