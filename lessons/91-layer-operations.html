STEP 74 · LAYER OPERATIONS

Layerの操作

匿名Layer、Save と Export、Reload

今日これだけ

Layerはファイルと1対1ではない 匿名Layerは保存先を持たず ExportとSaveは別物

公式情報に基づく説明

Layerを、ファイルから切り離して考える

ここまで「Layer＝1つのUSDAファイル」として扱ってきました。ほとんどの場面ではそれで正しいのですが、保存先を持たないLayerも作れます。これを匿名Layer（Anonymous Layer）と呼びます。

STEP 80で見たSession Layerも匿名Layerの一種です。作業中の一時的な内容を置く場所として、あるいは中身を組み立ててから保存先を決めたいときに使います。

保存まわりの操作にも区別があります。Save()はそのLayer自身のファイルへ書き戻します。Export()は別のファイルへ書き出します。匿名Layerには書き戻す先が無いので、Save()はできずExport()を使います。

OpenUSD Academy Note

dirtyという状態があります。読み込んでから変更が加えられたかどうかを表す真偽値で、Save()が必要かの判断に使えます。ツールで「保存されていません」と出すのは、この値を見ています。

USDA

Layer Stackを組む側のファイル

root.usdaUSDA
#usda 1.0
(
    defaultPrim = "City"
    metersPerUnit = 1
    subLayers = [
        @./look.usda@,
        @./base.usda@
    ]
    upAxis = "Y"
)

丸括弧の中のsubLayersが、このLayerが束ねる相手です。@ @で囲んだAsset Pathを角括弧に並べ、上ほど強い順になります。Pythonからはこの並びをsubLayerPathsとして直接読み書きできます。

Python

匿名Layerを作り、中身を移し、書き出す

layer_ops.pyPython
from pxr import Sdf, Usd, UsdGeom

stage = Usd.Stage.Open("city.usda")
layer = stage.GetRootLayer()

print("identifier :", layer.identifier.split("/")[-1])
print("dirty?     :", layer.dirty)

# 保存先を持たないLayerを作る
scratch = Sdf.Layer.CreateAnonymous("scratch")
print("匿名Layer  :", scratch.identifier)
print("anonymous? :", scratch.anonymous)

# 中身を丸ごと移す
scratch.TransferContent(layer)
print("移した後のrootPrims:", [str(p.path) for p in scratch.rootPrims])

# 匿名Layerは Save できないので Export する
print("Export ->", scratch.Export("copy.usda"))

# 外部で書き換えられたファイルを読み直す
print("Reload ->", layer.Reload())
実行結果Output
identifier : city.usda
dirty?     : False
匿名Layer  : anon:0x101664820:scratch
anonymous? : True
移した後のrootPrims: ['/City']
Export -> True
Reload -> False

匿名Layerのidentifierがanon:...で始まっています。ファイルパスではないので、他のLayerからこれを参照することは基本的にできません。

TransferContent()は中身を丸ごと置き換えます。差分の追加ではなく、移す先の元の内容は消えます。テンプレートから作り始めるときなどに使います。

Reload()がFalseを返しているのは、読み直す必要がなかったという意味です。変更されていないファイルに対しては何もしません。他のプロセスがファイルを書き換えた可能性があるときに呼びます。

Beginner notes

Stage.Save()とLayer.Save()

OpenUSD Academy Note

stage.Save()は、そのStageが持つファイルを持つLayerすべてを保存します。Session Layerのような匿名Layerは対象外です。「保存したのに反映されない」ときは、書き込み先がSession Layerになっていないかを疑います（STEP 80）。

個別に保存したいならlayer.Save()を使います。どのLayerへ書いているかはstage.GetEditTarget().GetLayer()で確かめられます。

よくある間違い

保存できない・消える

匿名LayerでSave()を呼ぶ

書き戻す先がありません。Export()でファイル名を指定します。

TransferContentを追加だと思う

中身を丸ごと置き換えます。移す先の元の内容は消えます。

Reloadが False を「失敗」だと読む

読み直す必要が無かった、という意味です。失敗ではありません。

匿名Layerを他から参照しようとする

anon:...はファイルパスではないので、解決できません。参照させたいならまずExport()します。

dirtyを見ずに毎回Saveする

変更が無くても書き込むと、更新時刻だけが変わって差分管理が煩雑になります。layer.dirtyを見てから保存します。

Glossary

このレッスンの用語

Anonymous Layer（匿名Layer）
保存先のファイルを持たないLayer。identifierがanon:で始まる。Session Layerもこの一種。
Save
そのLayer自身のファイルへ書き戻す操作。匿名Layerでは使えない。
Export
別のファイルへ書き出す操作。匿名Layerでも使える。
Reload
外部で書き換えられたファイルを読み直す操作。必要が無ければFalseを返す。
TransferContent
他のLayerの中身を丸ごと写す操作。移す先の元の内容は消える。
dirty
読み込んでから変更が加えられたかどうかを表す状態。
Edit Target
いまどのLayerへ書き込んでいるかを表す設定。stage.GetEditTarget()で確かめられる。
