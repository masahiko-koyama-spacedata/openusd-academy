STEP 110 · DEBUGGING

コマンドでStageを読む

構造・中身・見た目を、それぞれ別の道具で確かめます

今日これだけ

usdtreeで構造、usdcatで中身、usdrecordで見た目

公式情報に基づく説明

知りたいことごとに道具が違う

受け取ったUSDファイルを調べるとき、最初に使うのはコマンドです。構造だけ知りたいならusdtree、合成後の中身を読みたいならusdcat --flatten、見た目を確かめたいならusdrecordです。3つとも用途が違うので、疑問に合わせて選びます。

OpenUSD Academy Note

macOSにはApple USD Tools（/usr/bin/usdtreeなど）が最初から入っており、追加のインストールなしに使えます。このAcademyの描画結果も、すべてusdrecordで作っています。GUIのビューアが無くても、ここまで調べられます。

道具1

usdtree — 構造だけを見る

usdtree traversal.usdaコマンド
/
 `--World [def Xform]
     |--Robot [def Xform]
     |   |--Body [def Cube]
     |   `--Spare [def Cube]
     `--Styled [def Xform]

角括弧の中にSpecifierと型名が出ます。STEP 45 defで扱った読み方が、そのまま使えます。ファイルを開かずに階層の形だけ把握したいときに、いちばん速い方法です。

道具2

usdcat --flatten — 合成後の中身を読む

usdcat --flatten specifier-over.usdaコマンド
#usda 1.0
(
    defaultPrim = "World"
    doc = """Generated from Composed Stage of root layer …"""
    metersPerUnit = 1
    upAxis = "Y"
)

def Xform "World"
{
    def Cube "Retouched"
    {
        color3f[] primvars:displayColor = [(0.15, 0.35, 0.85)]
        double size = 1
        ...
    }
}

--flattenは合成した結果を1枚のUSDAとして書き出します。STEP 49 SublayerやSTEP 54 Referenceが解けたあとの姿がそのまま読めるので、「結局どうなったのか」を確かめるのに向いています。

OpenUSD Academy Note

ただし--flattenの結果には、どのLayerから来たかという情報が残りません。「なぜこの値なのか」を追いたいときは、STEP 69 Property Stackのほうを使います。用途がはっきり違うので、両方を覚えておいてください。

道具3

usdrecord — 見た目を確かめる

ターミナルコマンド
$ usdrecord --camera ShotCam --imageWidth 800 -c high \
    uniform.usda uniform.png

よく使う指定は3つです。--cameraでシーン内のカメラを選び、--imageWidthで幅を決め、-cで細かさを指定します。カメラを指定しないと自動のカメラになり、対象がぴったり収まりすぎて分かりにくい絵になりがちです。調べる用のカメラをシーンに1つ置いておくと、毎回同じ構図で比べられます。

疑問と道具の対応

Python

同じことをPythonでもできる

inspect.pyPython
from pxr import Sdf, Usd

stage = Usd.Stage.Open("traversal.usda")

# usdtree にあたるもの
for prim in stage.Traverse():
    depth = prim.GetPath().pathElementCount - 1
    print("%s%s [%s %s]" % ("  " * depth, prim.GetName(),
                            prim.GetSpecifier(), prim.GetTypeName()))
# World [Sdf.SpecifierDef Xform]
#   Robot [Sdf.SpecifierDef Xform]
#     Body [Sdf.SpecifierDef Cube]
#   Styled [Sdf.SpecifierDef Xform]

# usdcat --flatten にあたるもの
print(stage.Flatten().ExportToString()[:200])

コマンドで足りるうちはコマンドを使い、条件を付けて絞りたくなったらPythonへ移ります。Flatten()はusdcat --flattenと同じ結果を返すので、その中身をさらに処理したいときに便利です。

Beginner notes

調査用のカメラを置いておく

OpenUSD Academy Note

このAcademyの例には、どれもShotCamという名前のCameraが入っています。毎回同じ構図で描けるようにするためです。調べたいシーンにカメラが無いときは、overで1つ足すだけで済みます。元のファイルを触らずに調査用のカメラを持てるので、STEP 46 overの実用例としても分かりやすい使い方です。

よくある間違い

道具の守備範囲を取り違える

flattenの結果から原因を探す

どのLayerから来たかが消えています。原因を追うならProperty Stackです。

usdtreeに出ないPrimを「無い」と判断する

Inactiveなものやoverだけのものは、表示のされ方が違います。PythonのTraverseAll()で確かめます。

カメラを指定せずに描いて比べる

自動カメラは対象に合わせて動くので、構図が毎回変わります。比較には向きません。

usdcatで巨大なファイルを丸ごと出す

読み切れません。usdtreeで当たりを付けてから、必要な範囲だけ見ます。

Glossary

このレッスンの用語

usdtree
Stageの階層を、Specifierと型名付きのツリーで表示するコマンド。
usdcat
USDファイルの内容を表示するコマンド。--flattenで合成後の姿を出せる。
usdrecord
Stageを画像として描き出すコマンド。
Flatten
合成した結果を1枚のLayerにまとめること。Pythonではstage.Flatten()。
