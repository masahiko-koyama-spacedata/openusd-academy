Lofting

中身を開かなくても分かるように、要点を入口へ持ち上げます

今日これだけ

中身から計算した要約を、入口にも書いておく

公式情報に基づく説明

要約を上へ写す

STEP 67 Entry Pointを薄く保つと、中身を開かずに済みます。しかしそれでは「大きさ」のように、中身を見ないと分からない情報まで読めなくなります。そこで、中身から計算した要約を入口側へ書き写しておきます。これをLoftingと呼びます。代表例がextentsHintで、そのAssetのおおよその大きさを入口に持たせるものです。

OpenUSD Academy Note

Loftingは要約であって実体ではありません。中身を作り直したら、入口の要約も作り直す必要があります。古いままにしておくと、間違った情報を配ることになります。だから多くの現場では、アセットを書き出す処理の最後で、要約を自動的に計算し直します。

USDA

入口に大きさの要約を書く

lamp.usdaUSDA
def Xform "Lamp" (
    kind = "component"
    payload = @lamp_contents.usda@</Lamp>
)
{
    custom string academy:assetName = "Lamp"
    custom string academy:version = "1.0"
    float3[] extentsHint = [(-0.5, -0.06, -0.5), (0.5, 2.05, 0.5)]

    double3 xformOp:translate = (0, 0, 0)
    uniform token[] xformOpOrder = ["xformOp:translate"]
}

extentsHintは、そのAssetを囲む箱の最小と最大の角を表します。この値は中身（台・支柱・笠）から計算したものですが、書かれているのは入口のファイルです。中身のファイルを開かなくても読めます。

このUSDAファイルを開く

結果

Payloadを開かずに大きさが分かる

read_hint.pyPython
from pxr import Usd, UsdGeom

stage = Usd.Stage.Open("scene.usda", Usd.Stage.LoadNone)
lamp = stage.GetPrimAtPath("/World/Lamp_1")

print(lamp.IsLoaded())                              # False
print(UsdGeom.ModelAPI(lamp).GetExtentsHint())
# [(-0.5, -0.06, -0.5), (0.5, 2.05, 0.5)]

Payloadを一つも開いていない状態で、高さが約2.05あることが読み取れます。1000個のアセットが置かれたシーンでも、この値だけならすべて即座に読めます。画面に映る範囲を判断してから、必要なものだけLoad()するという流れが作れます。

Python

要約を計算して書き込む

loft_extents.pyPython
from pxr import Usd, UsdGeom

# 中身を開いた状態で計算する
stage = Usd.Stage.Open("lamp.usda")
prim = stage.GetPrimAtPath("/Lamp")

cache = UsdGeom.BBoxCache(Usd.TimeCode.Default(), [UsdGeom.Tokens.default_])
api = UsdGeom.ModelAPI(prim)

hint = api.ComputeExtentsHint(cache)
print(hint)                # [(-0.5, -0.06, -0.5), (0.5, 2.05, 0.5)]

api.SetExtentsHint(hint)   # 入口のファイルへ書き込む
stage.Save()

ComputeExtentsHintが中身から大きさを計算し、SetExtentsHintが入口へ書きます。書き出し処理の最後にこの2行を呼ぶようにしておけば、要約が古くなることを防げます。

Beginner notes

要約はAssetの座標系での値

OpenUSD Academy Note

extentsHintは、そのAsset自身の座標系での大きさです。シーンに置いたときの位置は含まれません。実際に、シーン側でtranslate = (-1.4, -1, 0)して置いたランプの世界座標での範囲を計算すると(-1.9, -1.06, -0.5)から(-0.9, 1.05, 0.5)になり、入口のextentsHintとは値が違います。入口の値に、置いた変換を掛けて使うと覚えてください。

よくある間違い

要約を手で書く

すぐに実体とずれます。必ず計算した値を書きます。

世界座標の値だと思って使う

Asset自身の座標系の値です。置いた変換を掛けてから使います。

要約を実体の代わりに使う
