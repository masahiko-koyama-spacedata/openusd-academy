AttributeとRelationship

値を持つ情報と、別の対象を指すつながりを読み分けます

今日これだけ

Attributeは値を持ち Relationshipは0個以上のPathを対象として持てる

公式情報に基づく説明

Propertyには二つの種類がある

Attributeは名前と一つのデータ型を持つ値です。Relationshipは型のないPropertyで、0個以上のPrim PathまたはProperty Pathを対象として持てます。どちらもPrimに属するPropertyですが、値と接続という役割が異なります。

OpenUSD Academy Note

まず「Attributeは値」「Relationshipは矢印」と覚え、実際の型とPathをコードで確認します。矢印の行き先をまだ設定していないRelationshipも有効です。

USDA

値とつながりを一つずつ書く

properties.usdaUSDA
#usda 1.0

def Xform "World"
{
    def Sphere "Ball"
    {
        double radius = 2
    }

    def "Selection"
    {
        custom rel members = </World/Ball>
    }
}

doubleは小数を扱える数値型、radiusはAttribute名、=は右の値を指定する記号です。customはカスタムProperty、relはRelationship、membersはその名前です。山括弧 < > は対象Pathを囲みます。

Python

Schema APIとRelationship APIで作る

create_properties.pyPython
from pxr import Usd, UsdGeom

stage = Usd.Stage.CreateNew("properties.usda")
UsdGeom.Xform.Define(stage, "/World")
ball = UsdGeom.Sphere.Define(stage, "/World/Ball")
ball.CreateRadiusAttr(2)

selection = stage.DefinePrim("/World/Selection")
members = selection.CreateRelationship("members", custom=True)
members.SetTargets([ball.GetPath()])
stage.Save()

CreateRadiusAttr(2)はSchema APIでradius Attributeを作ります。CreateRelationshipはRelationshipを作り、SetTargetsで対象を設定します。角括弧 [ ] はPythonのリストで、ここではPathを一つ入れています。

Beginner notes

記号を左から読む

OpenUSD Academy Note

USDAのインデントは所属を見やすくし、波括弧はPrimの中身を囲みます。引用符はPrim名を囲みます。Pythonの引用符は文字列、丸括弧は関数への入力、カンマは入力の区切りです。Pathの先頭の / はpseudo-rootを表します。

よくある間違い

値と接続を入れ替えない

Relationshipに数値を直接入れる

Relationshipが持つのは対象Pathです。数値はAttributeで表します。

対象Pathの山括弧を省く

USDAのRelationship対象は </World/Ball> のように山括弧で囲みます。

汎用APIだけを優先する

型付きSchemaが提供するAttributeは、公式ガイドの推奨どおりSchema固有APIを優先します。

Glossary

このレッスンの用語

Attribute
名前と一つのデータ型を持つ値のProperty。
Relationship
0個以上のPrim PathまたはProperty Pathを対象として持てる、型のないProperty。
Target
Relationshipが指すPrimまたはPropertyのPath。
custom
Schemaであらかじめ定義されていないカスタムPropertyを示す指定。
