STEP 67 · LAYER OFFSET

Layer Offset

同じAssetを、違う時間で再生します

今日これだけ

ReferenceやSublayerにはoffsetとscaleを付けられ 同じAssetを違う時間で再生できる

公式情報に基づく説明

合成のときに、時間そのものをずらす

STEP 39でTime Sampleを扱いました。では、時間で動くAssetを1つ作り、シーンに3体置いて少しずつタイミングをずらしたいときはどうするでしょうか。Assetを3つ複製するのは無駄です。

そのための仕組みがLayer Offsetです。ReferenceやPayload、Sublayerにoffsetとscaleを付けると、その先から来るTime Sampleの時刻が変換されます。offsetは平行移動、scaleは伸縮です。

大事なのは、これが合成のときに効くことです。Assetのファイルには一切手を触れません。同じファイルを、違う時間の見え方で何度でも参照できます。

OpenUSD Academy Note

向きに注意します。offset = 5は「参照先の時刻0が、こちらの時刻5に現れる」という意味です。つまり5だけ遅れて始まります。scale = 2は「参照先の1が、こちらの2になる」ので、2倍の時間をかけてゆっくり進みます。速くしたいならscaleは1より小さくします。

USDA

同じAssetを、そのままと、ずらして参照する

anim.usda — 参照される側USDA
def Xform "Anim"
{
    double3 xformOp:translate.timeSamples = {
        0: (0, 0, 0),
        10: (10, 0, 0),
    }
    uniform token[] xformOpOrder = ["xformOp:translate"]
}
scene.usda（抜粋）USDA
# そのまま参照する。0〜10 で動く
def Xform "A" (
    prepend references = @./anim.usda@
)
{
}

# offset = 5 で5だけ遅らせ、scale = 2 で倍の時間をかける
def Xform "B" (
    prepend references = @./anim.usda@ (offset = 5; scale = 2)
)
{
}

@./anim.usda@のうしろの丸括弧が Layer Offset です。offsetとscaleをセミコロンで区切って書きます。@ @がAsset Path、その後ろの丸括弧がその参照に対する指定、という読み方になります。

このUSDAファイルを開く

Python

時刻ごとの値を並べて確かめる

layer_offset.pyPython
from pxr import Sdf, Usd, UsdGeom

stage = Usd.Stage.Open("scene.usda")

for name in ("A", "B"):
    op = UsdGeom.Xformable(
        stage.GetPrimAtPath("/World/" + name)).GetOrderedXformOps()[0]
    print("/World/%s :" % name,
          [(t, tuple(op.Get(t))[0]) for t in (0.0, 5.0, 10.0, 15.0, 25.0)])
実行結果Output
/World/A : [(0.0, 0.0), (5.0, 5.0), (10.0, 10.0), (15.0, 10.0), (25.0, 10.0)]
/World/B : [(0.0, 0.0), (5.0, 0.0), (10.0, 2.5), (15.0, 5.0), (25.0, 10.0)]

Aはt=0からt=10で0から10へ動き、そのあとは止まります。Bはt=5まで0のまま待ち、そこから動き始めてt=25でようやく10に届きます。5だけ遅れて、2倍の時間をかけた、という指定がそのまま出ています。

layer_offset.py（続き）Python
# PythonからLayer Offsetを付けて参照する
prim = stage.GetPrimAtPath("/World/B")
prim.GetReferences().AddReference("./anim.usda", Sdf.LayerOffset(5.0, 2.0))

# Sublayerに付けるときは、こちらの配列を使う
layer = stage.GetRootLayer()
print(layer.subLayerOffsets)

Diagram

offsetとscaleが時刻をどう変えるか

式にするとこちらの時刻 = 参照先の時刻 × scale + offsetです。参照先の0は0 × 2 + 5 = 5、参照先の10は10 × 2 + 5 = 25。上の実行結果と一致します。

USDA → Python mapping

行ごとに対応させる

  1. USDA

    references = @./anim.usda@ (offset = 5; scale = 2)↓

    Python

    prim.GetReferences().AddReference("./anim.usda", Sdf.LayerOffset(5.0, 2.0))

  2. USDA

    payload = @./c.usda@ (offset = 3)↓

    Python

    prim.GetPayloads().AddPayload("./c.usda", layerOffset=Sdf.LayerOffset(3.0))

  3. USDA

    subLayers = [@./a.usda@ (offset = 2)]↓

    Python

    layer.subLayerOffsets[0] = Sdf.LayerOffset(2.0)

Beginner notes

時間だけが変わり、値は変わらない

OpenUSD Academy Note

Layer Offsetが影響するのはTime Sampleの時刻だけです。defaultで書いた時間に依存しない値は変わりません。STEP 39で見た「defaultとTime Sampleは別物」という区別が、ここで効いてきます。

また、StageのstartTimeCode・endTimeCodeは自動で広がりません。ずらした結果が範囲の外へ出ると、再生しても見えないことがあります。ずらした分を見込んで、シーン側の範囲を広げておきます。

よくある間違い

ずらしたのに合わない

offsetの向きを逆に考える

offset = 5は5だけ遅れて始まります。早めたいなら負の値です。

scaleで速くしようとして大きい値を入れる

scale = 2は2倍の時間をかける、つまり遅くなります。速くしたいなら0.5のように1より小さくします。

startTimeCodeを広げ忘れる

ずらした結果が範囲外に出ると、再生範囲に現れません。値そのものは正しく合成されているので、原因が分かりにくい間違いです。

defaultで書いた値がずれると思う

Layer OffsetはTime Sampleの時刻にだけ効きます。defaultの値は動きません。

Glossary

Layer Offset

SdfLayerOffset

Layerが持つ、各Sublayerに対するLayer Offsetの配列。
