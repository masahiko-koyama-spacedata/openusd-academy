LESSON 23

Primvars

補間・index・階層継承を扱える特別なAttribute

今日これだけ

Primvar本体はMetadataではなくAttribute

公式情報に基づく説明

公式: PrimvarsはUV、vertex color、deformation dataなどを保持し、Interpolation、index、namespace inheritanceを扱えます。

OpenUSD Academy Note: 値の個数はInterpolationとTopologyに合わせます。

なんのためにあるのか

Shaderへ値を渡し、Surface上へ値を分配するためです。

Diagram

USDA

color3f[] primvars:displayColor = [(1, 0, 0)] (
    interpolation = "constant"
)

コロンはnamespace、丸括弧はAttribute Metadataです。

Python

pv = UsdGeom.PrimvarsAPI(prim).CreatePrimvar(
    "displayColor", Sdf.ValueTypeNames.Color3fArray)
pv.SetInterpolation(UsdGeom.Tokens.constant)

USDA → Python

primvars:displayColor → CreatePrimvar("displayColor", ...)

例題

UVやFace色にPrimvarを使う理由は？ Surface上のInterpolationを表せるためです。

よくある間違い

原因: PrimvarをMetadataだと思う。
解決策: 本体はtyped Attributeで、interpolationがMetadataです。

用語集

Primvar
補間等の機能を持つAttribute。
Topology
Point・Faceの接続構造。
