STEP 55 · STAGE METADATA

upAxis

どの軸が「上」なのかを、Stageに記録します

今日これだけ

upAxisはYかZのどちらかを宣言するだけで 形を自動では回転しない

公式情報に基づく説明

上方向の約束をLayerに書く

upAxisは、そのLayerで「上」とみなす軸を示すLayer Metadataです。指定できるのは"Y"か"Z"のどちらかで、書かなかった場合の既定値は"Y"です。metersPerUnitと同じく、これは宣言にすぎません。上方向が違うアセットを読み込んでも、OpenUSDが自動で回転させることはありません。

OpenUSD Academy Note

DCCツールによって上方向の慣習が違います。Y-upの世界で作られたキャラクターを、Z-upの世界へそのまま置くと、寝転んだ状態になります。この食い違いは初学者がいちばん最初に遭遇する「なぜか倒れている」問題の正体です。

USDA

3本の柱で違いを並べる

up-axis.usda（抜粋）USDA
#usda 1.0
(
    defaultPrim = "World"
    metersPerUnit = 1
    upAxis = "Y"
)

def Xform "World"
{
    def Xform "BuiltUpY"
    {
        def Cylinder "Trunk"
        {
            double height = 1.5
            double radius = 0.18
            uniform token axis = "Y"
        }
        def Sphere "Crown"
        {
            double radius = 0.42
            double3 xformOp:translate = (0, 0.75, 0)
            uniform token[] xformOpOrder = ["xformOp:translate"]
        }
        double3 xformOp:translate = (-2.3, 0, 0)
        uniform token[] xformOpOrder = ["xformOp:translate"]
    }
}

このStageはupAxis = "Y"です。BuiltUpYはCylinderのaxisを"Y"にし、球も(0, 0.75, 0)すなわちY方向へ持ち上げているので、Stageの約束どおり縦に立ちます。同じファイルには、これをZ方向に作ったBuiltUpZと、それを補正したBuiltUpZFixedも入っています。

このUSDAファイルを開く

結果

Z方向に作った柱だけが倒れる

直し方

X軸まわりに90度回す

up-axis.usda（該当部分）USDA
    def Xform "BuiltUpZFixed"
    {
        double3 xformOp:translate = (2.3, 0, 0)
        float xformOp:rotateX = -90
        uniform token[] xformOpOrder = ["xformOp:translate", "xformOp:rotateX"]
    }

Z-upのアセットをY-upのStageへ入れるときは、X軸まわりに-90度回します。こうすると、もとの+Z方向が+Y方向を向きます。逆にY-upのアセットをZ-upのStageへ入れるときは+90度です。符号を取り違えると上下がひっくり返るので、必ず描画して確かめてください。

Python

Tokensで軸を指定する

up_axis.pyPython
from pxr import Usd, UsdGeom

stage = Usd.Stage.CreateNew("scene.usda")

UsdGeom.SetStageUpAxis(stage, UsdGeom.Tokens.z)
print(UsdGeom.GetStageUpAxis(stage))   # Z

UsdGeom.SetStageUpAxis(stage, UsdGeom.Tokens.y)
print(UsdGeom.GetStageUpAxis(stage))   # Y

stage.Save()

UsdGeom.Tokens.yとUsdGeom.Tokens.zは、USDAに書く"Y"と"Z"に対応する定数です。小文字のyで参照して、返ってくる値は大文字のYである点に注意してください。

Beginner notes

Cylinderのaxisは別のもの

OpenUSD Academy Note

UsdGeomCylinderやUsdGeomConeにはaxisというAttributeがあり、その形自体がどの軸に沿って伸びるかを決めます。既定値は"Z"です。これはStageのupAxisとは別の設定で、名前が似ているだけです。Y-upのStageで円柱を立てたいときは、Cylinderのaxisも"Y"にします。

よくある間違い

宣言だけで直ると思う

upAxisを書き換えれば向きが直ると思う

StageのupAxisを"Z"へ変えても、既に置いてある他のアセットの向きが変わるだけで、食い違いは解消しません。回すべきは、向きが違うアセットのほうです。

回す軸を間違える

YとZの入れ替えはX軸まわりの回転です。Y軸やZ軸まわりに回しても上下は変わりません。

符号を確かめずに90度回す

+90と-90では上下が逆になります。描画して確認するのが確実です。

Cylinderのaxisと混同する

形の伸びる方向はPrimごとのaxis、Stageの上方向はupAxisです。

Glossary

このレッスンの用語

upAxis
そのLayerで上とみなす軸を示すLayer Metadata。"Y"または"Z"。
Y-up / Z-up
上方向をどの軸に取るかという座標系の慣習。ツールによって異なる。
axis（Cylinder・Cone）
その形自体が伸びる方向を決めるAttribute。既定値は"Z"。
xformOp:rotateX
X軸まわりにPrimを回転させるXformOp。上方向の補正に使う。
