STEP 06 · USDZ AND RESOLUTION

USDZとAsset Resolution

1ファイルにまとめ、パスを実ファイルへ結び付けます

今日これだけ

usdzは無圧縮で整列した入れ物で 展開せずにそのまま開けるAsset Pathは@ @で書き 解決はArが担う

公式情報に基づく説明

1ファイルで渡したいが、展開はしたくない

STEP 05でUSDZに触れました。ここでは、実際に作って中身を見ます。

USDのAssetは、本体のUSDAとテクスチャの画像が別ファイルになります。誰かに渡すときは全部まとめたいところですが、普通のzipにすると開くたびに展開が必要になります。

usdzはこれを解きます。中身は無圧縮で、しかも決まった境界に整列して並べられます。そのため、展開せずに「このファイルの何バイト目から何バイト」を直接読めます。数百MBのテクスチャが入っていても、必要な部分だけを読めるということです。

もう一つの軸がAsset Path の解決です。@./checker.png@と書いたパスが、実際にどのファイルを指すのかを決める仕組みをAr（Asset Resolver）と呼びます。ローカルのファイルだけでなく、社内のAsset管理システムのIDを解決させることもできます。

OpenUSD Academy Note

usdzの中では、Asset Pathの解決結果がmodel.usdz[checker.png]のような角括弧付きの形になります。「このパッケージの中のこのファイル」という意味です。実ファイルとして存在しないので、普通のファイル操作では開けません。読むときはUSDのAPIを通します。

USDA

外部ファイルを参照するAsset

model.usda（抜粋）USDA
def Mesh "Model"
{
    uniform token subdivisionScheme = "none"
    int[] faceVertexCounts = [4]
    int[] faceVertexIndices = [0, 1, 2, 3]
    point3f[] points = [(-1, -1, 0), (1, -1, 0), (1, 1, 0), (-1, 1, 0)]
    custom asset customTexture = @./checker.png@
}

@ @で囲まれているのがAsset Pathです。./checker.pngはこのファイルから見た相対パスで、書いた時点ではまだどのファイルか確定していません。確定させるのが解決（resolve）です。

このUSDAファイルを開く

Python

usdzを作り、中身を見る

make_usdz.pyPython
import os
import zipfile
from pxr import Sdf, Usd, UsdUtils

# 本体と、それが参照するファイルをまとめて1つにする
ok = UsdUtils.CreateNewUsdzPackage(Sdf.AssetPath("model.usda"), "model.usdz")
print("作成:", ok, "/ サイズ:", os.path.getsize("model.usdz"), "bytes")

# 中身は普通のzipとしても読める
with zipfile.ZipFile("model.usdz") as z:
    for info in z.infolist():
        print("  %-16s size=%-6d compress_type=%d offset=%d"
              % (info.filename, info.file_size,
                 info.compress_type, info.header_offset))
実行結果Output
作成: True / サイズ: 893 bytes
  model.usda       size=344    compress_type=0 offset=0
  checker.png      size=159    compress_type=0 offset=408

compress_type=0が無圧縮という意味です。offsetが0と408に並んでいるのも、整列して置かれている証拠です。CreateNewUsdzPackageは、本体が参照しているファイルを自動でたどって集めます。テクスチャを1つずつ指定する必要はありません。

Python

展開せずに開き、必要なら展開する

read_usdz.pyPython
from pxr import Ar, Usd, UsdUtils

# usdz をそのまま Stage として開ける
stage = Usd.Stage.Open("model.usdz")
print("defaultPrim :", stage.GetDefaultPrim().GetPath())

attr = stage.GetPrimAtPath("/Model").GetAttribute("customTexture").Get()
print("Asset Path  :", attr.path)
print("解決後       :", str(attr.resolvedPath))

# 中身をファイルとして取り出したいとき
print("extract ->", UsdUtils.ExtractUsdzPackage("model.usdz", "extracted"))
実行結果Output
defaultPrim : /Model
Asset Path  : ./checker.png
解決後       : /private/tmp/uz/model.usdz[checker.png]
extract -> True

Usd.Stage.Open("model.usdz")がそのまま通ります。展開の手順は要りません。解決後のパスがmodel.usdz[checker.png]になっている点が、usdzの中を直接指していることを表しています。

attr.pathが書かれたままのパス、attr.resolvedPathが解決後のパスです。この2つを分けて持っているのがSdf.AssetPathの特徴で、STEP 08で見たassetというValue Typeの実体です。

Asset Resolution

書かれたパスから、実際のファイルを決める

resolve.pyPython
from pxr import Ar, Usd

stage = Usd.Stage.Open("model.usdz")
resolver = Ar.GetResolver()
print("実装:", type(resolver).__name__)

# Stage が持つ解決の文脈を使う
with Ar.ResolverContextBinder(stage.GetPathResolverContext()):
    print("Resolve('model.usda') :", str(resolver.Resolve("model.usda")))
    print("Resolve('nope.usda')  :", repr(str(resolver.Resolve("nope.usda"))))
実行結果Output
実装: Resolver
Resolve('model.usda') : /private/tmp/uz/model.usda
Resolve('nope.usda')  : ''

存在しないパスを解決すると空文字が返ります。例外は出ません。これがSTEP 119で見た「参照はあるのに子がいない」という壊れ方の正体です。解決に失敗しても処理は続き、ただ中身が来ないだけになります。

既定のResolverは、ファイルシステム上の相対パス・絶対パスを解決します。組織によっては、独自のResolverを差し込んで@asset://bench/v3@のようなIDを解決させます。USDA側の書き方は変わらず、解決の実装だけが差し替わるのがこの仕組みの要点です。

Beginner notes

usdzは編集する形式ではない

OpenUSD Academy Note

usdzは配布のための形です。無圧縮で整列している都合上、中のファイルを差し替えるとサイズが変わって配置が崩れます。編集は元のUSDAで行い、配るときに作り直すのが基本です。

usdcheckerにはusdz向けの検査もあり、--arkitを付けるとApple ARKitが受け付ける制約（ファイル形式や構造の条件）まで確認できます。iOSやvisionOSへ渡すなら、そちらで作るCreateNewARKitUsdzPackageを使います。

よくある間違い

まとめたのに開けない・見つからない

絶対パスで書いたままusdzにする

@/Users/me/tex/checker.png@のような絶対パスは、他の環境では解決できません。Asset Pathは相対で書くのが原則です。

解決に失敗しても例外が出ると思う

見つからないときは空文字が返るだけです。処理は続き、中身が来ないという形で現れます。

usdzの中のファイルを普通に開こうとする

model.usdz[checker.png]は実ファイルではありません。読むならUSDのAPIを通すか、いったん展開します。

usdzを圧縮して小さくしようとする

無圧縮であることが「展開せずに読める」ことの前提です。圧縮するとその利点が消えます。

usdzを直接編集して配り直す

配置が崩れます。元のUSDAを直して作り直します。

Glossary

このレッスンの用語

USDZ
USDと参照先のファイルを1つにまとめた配布用の形式。中身は無圧縮で整列しており、展開せずに読める。
CreateNewUsdzPackage
本体が参照しているファイルを自動で集めてusdzを作るPython API。
ExtractUsdzPackage
usdzの中身をファイルとして取り出すPython API。
Ar（Asset Resolver）
書かれたAsset Pathから実際のファイルを決める仕組み。実装を差し替えられる。
Sdf.AssetPath
asset型の値。書かれたままのpathと、解決後のresolvedPathの2つを持つ。
Resolver Context
解決を行うときの文脈。Stageごとに持ち、Ar.ResolverContextBinderで束縛して使う。
