記述を読む

variants.usdaUSDA
#usda 1.0

def Sphere "Ball" (
    variants = { string size = "large" }
    prepend variantSets = "size"
) {
    variantSet "size" = {
        "small" { double radius = 1 }
        "large" { double radius = 3 }
    }
}

#usda 1.0はUSDAヘッダーです。引用符は名前や文字列、波括弧はPrim内容、丸括弧はMetadata、/はPrim Pathの階層を表します。インデントは所属を読みやすくするためにそろえます。

結果

どのOpinionが見えるか

large選択時は3、small選択時は1。ただし同じPropertyへLocal値があれば、LはVより強いのでLocalが勝ちます。

Python

合成結果をAPIで確認する

inspect.pyPython
from pxr import Usd
stage = Usd.Stage.Open("variants.usda")
v = stage.GetPrimAtPath("/Ball").GetVariantSet("size")
v.SetVariantSelection("small")
print(stage.GetPrimAtPath("/Ball").GetAttribute("radius").Get())

ピリオドはオブジェクトの機能へ進む記号、丸括弧は関数への入力、引用符はPathやファイル名、字下げはPythonの処理範囲を表します。

例題

用途を判断する

問題: 球のsmallとlargeを選択する

答え: V · Variant Sets。色、形状、LODなど、有限個の承認済み選択肢を名前で切り替える場面。

公式の論点を残す

Set・Variant・Selectionを分ける

公式: Variant Setは名前付きの選択肢の集合、Variantはその中の一つ、Variant Selectionは現在選ばれている名前です。選択されたVariant内のOpinionだけが、そのSetを定義したPrimで合成されます。

公式: PythonでVariant内へ書くには、Variantを追加して選択し、GetVariantEditContext()の中でOpinionをauthorします。Selectionは別Layerにも書けるため、同じAssetの各Referenceで別のVariantを選べます。最終結果には通常の強度順序が適用されます。

OpenUSD Academy Note

SetVariantSelection()だけではVariantの中身は作りません。「選択肢を定義する処理」と「どれを選ぶか」を別操作として読みます。

よくある間違い

Variantを自由な微調整に使う

誤解

原因: Arcの役割と強度順序を混同しています。

解決策: 選択肢が際限なく増えます。ショット固有の一回限りの調整はLocal Opinionを検討します。
