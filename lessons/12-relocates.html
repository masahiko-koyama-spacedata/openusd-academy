E · rElocates

rElocatesは合成時にnamespace上のPrim Pathを移し替えるArc

今日これだけ

rElocatesは合成時にnamespace上のPrim Pathを移し替えるArc

公式情報に基づく説明

このArcが解決すること

既存アセットの子Primを新しいPathへ移す

OpenUSD Academy Note

参照アセットの階層を非破壊で再構成する高度なnamespace編集。初学者はまずReferenceとPath変換を理解してから使います。

Diagram

Opinionから合成結果へ

USDA

記述を読む

relocates.usdaUSDA
#usda 1.0

over "World" (
    relocates = {
        <Chair>: <Furniture/Chair>
    }
) {
}

#usda 1.0はUSDAヘッダーです。引用符は名前や文字列、波括弧はPrim内容、丸括弧はMetadata、/はPrim Pathの階層を表します。インデントは所属を読みやすくするためにそろえます。

結果

どのOpinionが見えるか

sourceの/World/Chairは、合成結果では/World/Furniture/Chairへ移ります。これはファイル内容のコピーや単純な名前変更ではありません。

Python

合成結果をAPIで確認する

inspect.pyPython
from pxr import Sdf, Usd
stage = Usd.Stage.Open("relocates.usda")
world = stage.GetPrimAtPath("/World")
print(world.GetMetadata("relocates"))

ピリオドはオブジェクトの機能へ進む記号、丸括弧は関数への入力、引用符はPathやファイル名、字下げはPythonの処理範囲を表します。

例題

用途を判断する

問題: 既存アセットの子Primを新しいPathへ移す

答え: E · rElocates。参照アセットの階層を非破壊で再構成する高度なnamespace編集。初学者はまずReferenceとPath変換を理解してから使います。

公式情報の範囲

NVIDIA教材の未整備部分を補完しすぎない

公式: rElocatesはLIVRPSへ後から加わったComposition Arcで、現在の略語LIVERPSではEに当たります。NVIDIA Learn OpenUSDは2026年8月6日時点で導入を説明していますが、個別モジュールはまだ提供していません。

OpenUSD公式: relocatesは合成されたnamespaceでPrimを移動するためのOpinionです。単なる文字列置換ではなく、Compositionが扱うPathの対応に参加します。
