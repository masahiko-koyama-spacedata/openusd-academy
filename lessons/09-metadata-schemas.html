MetadataとSchema

補助情報とデータの設計図を分けます

今日これだけ

Metadataは時間変化しない補助情報 SchemaはPrimの意味と使えるPropertyを定める

公式情報に基づく説明

情報と設計図は別の役割

MetadataはPrim・Property・Layerに付く名前と値の組で、時間サンプルを持ちません。Schemaはデータを記述・取得する構造化APIで、IsA SchemaとAPI Schemaがあります。

OpenUSD Academy Note

Metadataを付箋、Schemaを記入欄の設計図として考えてから正式な違いへ戻ります。

USDA

documentationとSphereを書く

metadata-schema.usdaUSDA
#usda 1.0

def Sphere "Ball" (
    documentation = "学習用の球"
)
{
    double radius = 2
}

Prim名の後の丸括弧はPrim Metadataの範囲です。documentationがMetadataキー、引用符内が値です。SphereはIsA Schemaによる型、radiusはAttributeです。

Python

Schema APIとMetadata APIを使う

create_metadata.pyPython
from pxr import Usd, UsdGeom

stage = Usd.Stage.CreateNew("metadata-schema.usda")
ball = UsdGeom.Sphere.Define(stage, "/Ball")
ball.GetPrim().SetDocumentation("学習用の球")
ball.CreateRadiusAttr(2)
stage.Save()

GetPrim()でSchemaオブジェクトからPrimを取得し、SetDocumentation()でMetadataを設定します。

Beginner notes

二種類の丸括弧を区別する

OpenUSD Academy Note

USDAのPrim名後の丸括弧はMetadata、波括弧はPrimの内容です。Pythonの丸括弧はAPIへの入力、引用符は文字列、スラッシュはPrim Pathです。インデントは所属を見やすくします。

よくある間違い

MetadataとAttributeを混ぜない

Metadataをアニメーションさせる

原因: Metadataは時間サンプルを持ちません。

解決策: 時間変化する値にはAttributeを使います。

Schemaが動作を実行すると思う

解決策: Schemaは主にデータモデルと解釈ルールを定めるものとして読みます。

Glossary

このレッスンで出た言葉

Metadata
時間変化しない補助情報。
Schema
データの構造と意味を定める設計図。
IsA Schema
Primが何であるかを定めるSchema。
API Schema
Primへ機能やPropertyを追加するSchema。
