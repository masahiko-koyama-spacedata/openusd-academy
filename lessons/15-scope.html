STEP 17 · SCENE DESCRIPTION

Scope

Primを移動させず、用途ごとに整理するための入れ物

今日これだけ

整理だけならScopeを使う

Scopeは子Primをまとめますが、変換機能を持ちません。位置・回転・大きさを親から与えたいときはXformを使います。

公式情報に基づく説明

大きなScenegraphを読みやすくする

公式: Scopeはscenegraph内でPrimを論理的にまとめるためのconcrete IsA Schemaです。Geometryや描画対象そのものを表さず、transformabilityを持たない軽量な整理用コンテナです。

公式: Scopeの下に置いたtransformableな子Primは通常どおり評価されます。Actors、Environments、Materials、Lightsなど、役割ごとのまとまりを作る用途があります。

OpenUSD Academy Note

フォルダに近い役割ですが、ただの見た目上のグループではありません。/World/Geometry/ChairのようにScope名もPrim Pathの一部になります。

なんのためにあるのか

変換と整理を分離する

すべての親をXformにすると、そのPrimに変換を記述できてしまいます。Scopeを使うと「ここは移動用ではなく整理用」という意図をSchemaで伝えられます。ツールや人がscenegraphを読んだとき、役割を判断しやすくなります。

Diagram

Worldの下を役割で分ける

USDA

GeometryとLightsを分ける

scope.usdaUSDA
#usda 1.0

def Xform "World" {
    def Scope "Geometry" {
        def Cube "Box" {
            double size = 2
        }
    }

    def Scope "Lights" {
        def DistantLight "Sun" {
        }
    }
}

defはPrimを定義するSpecifier、ScopeはPrimの型、引用符内はPrim名です。波括弧はPrimの内容、インデントは親子関係を読みやすくします。/World/Geometry/BoxのスラッシュはPathの階層を区切ります。

一行ずつ読む

def Scope "Geometry"を分解する

  1. def

    Stageに存在するPrimとして定義します。

  2. Scope

    変換を持たない整理用Prim Schemaを指定します。

  3. "Geometry"

    Prim名です。親が/WorldなのでPathは/World/Geometryになります。

  4. { }

    Scopeの子PrimやPropertyを書く範囲です。

Python

Scopeを定義して型を確認する

create_scope.pyPython
from pxr import Usd, UsdGeom

stage = Usd.Stage.CreateNew("scope.usda")
world = UsdGeom.Xform.Define(stage, "/World")
geometry = UsdGeom.Scope.Define(stage, "/World/Geometry")
UsdGeom.Cube.Define(stage, "/World/Geometry/Box")

print(geometry.GetPrim().IsA(UsdGeom.Scope))
stage.Save()

fromはpackageからmoduleを読み込む語、ピリオドは機能へ進む記号、丸括弧は関数へ値を渡す記号です。IsA()はPrimが指定Schemaの型かを確認します。出力はTrueです。

例題

ScopeとXformを選ぶ

問題1 Materialsを用途別に整理する

答え: Scope。整理が目的で、親から位置を変える必要がないためです。

問題2 Robot全体を一度に回転する

答え: Xform。子へ階層変換を与える必要があるためです。

問題3 Actorsをまとめて一時的に無効化する

答え: Scopeをrootにしてまとめる方法があります。Scope Primをinactiveにすると、その子孫もStageからpruneされます。activeの詳細は独立レッスンで扱います。

よくある間違い

ScopeをXformの代わりにしない

Scopeへtranslateを書こうとする

原因: Scopeを一般的な変換グループだと考えています。

解決策: 移動させる親にはXformを使います。Scopeはtransformableではありません。

Scope名はPathに入らないと思う

原因: UI上のフォルダ表示だけだと考えています。

解決策: ScopeもPrimです。Geometryの子Boxは/World/Geometry/Boxになります。

Scopeの子は変換できないと思う

原因: 親の非transformable性を子へ混同しています。

解決策: Scope自身は変換できませんが、子のCubeやXformは自身のxformOpで変換できます。

Glossary

このページで出た言葉

Scope
変換を持たず、Primを論理的に整理するconcrete IsA Schema。
transformability
xformOpによって空間変換を記述できる性質。
IsA Schema
Primが何であるかをtypeNameで示すSchema。
inactive
Primと子孫をComposition結果から一時的に除外する状態。詳細は後続レッスンで扱う。
