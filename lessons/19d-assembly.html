STEP 64 · MODEL HIERARCHY

assembly

複数のModelを組み合わせた公開可能なaggregate Assetを示すgroupのsubkind

今日これだけ

assemblyは意味のある組み合わせとして再利用するgroup

単なる分類用groupではなく、NeighborhoodやFactory Cellのように一つのaggregate Assetとして扱うまとまりです。

公式情報に基づく説明

複数Assetから大きなAssetを作る

公式: assemblyはgroupのsubkindで、複数のModelからなるaggregate Assetを表します。assemblyはassembly、group、componentを子孫に持てます。

公式: componentがHouseなら、複数のHouseやTreeを組み合わせたNeighborhoodやCityはassemblyの候補です。

OpenUSD Academy Note

「子が複数ある」だけではassemblyにしません。そのまとまり自体を名前付きAssetとして公開・配置・再利用するかで判断します。

なんのためにあるのか

aggregateを一つのAssetとして扱う

Factory Cell、Neighborhood、Vehicle FleetなどをまとめてReferenceし、BoundsやModel単位の操作を高水準で行うために使います。

USDA

Neighborhoodをassemblyにする

assembly.usdaUSDA
#usda 1.0

def Xform "Neighborhood" (
    kind = "assembly"
) {
    def Scope "Houses" (
        kind = "group"
    ) {
        def Xform "House_01" (
            kind = "component"
        ) {
        }
    }
}

丸括弧はMetadata、波括弧は子Primの範囲です。assembly、group、componentは引用符で囲むtoken値です。

Python

assemblyを設定する

create_assembly.pyPython
from pxr import Kind, Usd, UsdGeom

stage = Usd.Stage.CreateNew("assembly.usda")
root = UsdGeom.Xform.Define(stage, "/Neighborhood")
Usd.ModelAPI(root).SetKind(Kind.Tokens.assembly)

print(root.GetPrim().IsGroup())
print(Usd.ModelAPI(root).GetKind())
stage.Save()

assemblyはgroupのsubkindなのでIsGroup()はTrueです。GetKind()はassemblyを返します。

USDA → Python mapping

assembly Metadataを対応させる

  1. kind = "assembly"↓SetKind(Kind.Tokens.assembly)
  2. prim.IsGroup()

    assemblyがgroup系Kindであることを確認します。

例題

groupとassemblyを選ぶ

Propsを種類別に整理するだけ

答え: group。分類用の高水準コンテナだからです。

完成したFactory Cellを別Sceneへ配置する

答え: assembly。複数Assetのまとまり自体をaggregate Assetとして再利用するためです。

よくある間違い

大きいという理由だけでassemblyにしない

子が多ければassemblyだと思う

原因: Asset境界ではなくPrim数で判断しています。

解決策: まとまり自体を公開・再利用するaggregateかで判断します。

assemblyをcomponentの下へ置く

原因: componentがleaf modelである規則を忘れています。

解決策: assemblyを上位へ置き、その下へcomponentを配置します。
