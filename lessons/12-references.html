R · ReferencesとdefaultPrim

Referenceは別LayerのPrim階層を参照元Primへ接ぎ木し、Pathを新しいnamespaceへ変換する

今日これだけ

Referenceは別LayerのPrim階層を参照元Primへ接ぎ木し、Pathを新しいnamespaceへ変換する

公式情報に基づく説明

このArcが解決すること

defaultPrimのChairを/World/HeroChairへ参照する

OpenUSD Academy Note

完成したアセットを複数のPathへ再利用する場面。参照先Prim Pathを省略するなら、参照先Layerに有効なtop-level defaultPrimが必要です。

Diagram

Opinionから合成結果へ

USDA

記述を読む

shot.usdaUSDA
# asset.usda
#usda 1.0
(defaultPrim = "Chair")
def Xform "Chair" {
    def Cube "Seat" {}
}

# shot.usda
#usda 1.0
def Xform "World" {
    def Xform "HeroChair" (
        references = @./asset.usda@
    ) {}
}

#usda 1.0はUSDAヘッダーです。引用符は名前や文字列、波括弧はPrim内容、丸括弧はMetadata、/はPrim Pathの階層を表します。インデントは所属を読みやすくするためにそろえます。

結果

どのOpinionが見えるか

assetの/Chair/Seatは、結果では/World/HeroChair/Seat。defaultPrimのroot名Chairを子として残すのではなく、HeroChairへ接ぎ木してPath変換します。

試験で問われるPath

defaultPrimと参照先Pathを分ける

  1. 参照元

    @./asset.usda@

    Prim Pathを省略したため、Layer MetadataのdefaultPrim = "Chair"が入口になります。

  2. 参照先

    /World/HeroChair

    参照元の/Chairが、このPrimへ対応します。

  3. 子Primの結果

    /Chair/Seat → /World/HeroChair/Seat

    参照元rootの名前ChairはPathへ一段追加されません。

OpenUSD Academy Note

例題: asset.usdaに/Chair/Seatと/Lampがあり、defaultPrimがChairなら、Prim Path省略のReferenceで入るのはChair階層です。Lampを入れるには@./asset.usda@</Lamp>と明示します。

例題

結果のPathを答える

問題: defaultPrim = "Chair"のファイルに/Chair/Seatがあります。これを/Set/Prop_01へPrim Path省略でReferenceしました。Seatの合成後Pathはどれですか。

公式の論点を残す

External・Internal・prepend・Encapsulation

公式: External Referenceは別LayerのPrim、Internal Referenceは同じLayer内のPrimを対象にできます。Referenceは対象Primのnamespaceを参照先Primへ接ぎ木し、Prim名とPathを新しいnamespaceへ変換します。

公式: prepend referencesは、弱いLayerですでに存在するReferenceより前へ項目を追加し、より強く寄与させます。UsdReferences.AddReference()の既定動作もprependです。

公式: Reference対象の下に収まる内容はencapsulatedです。対象の外側にあるPrimは自動では一緒に入りません。必要な依存関係を入口Primの下へ収めるAsset Structureが重要です。

OpenUSD Academy Note

Referenceは「ファイルを読む」だけではありません。「どのPrimを入口にし、どのPathへ接ぎ木するか」をセットで追います。

よくある間違い

defaultPrimがなくてもファイル全体が入ると思う

誤解

原因: Arcの役割と強度順序を混同しています。

解決策: Prim Path省略時は入口を解決できず、空の参照と警告になります。defaultPrimを設定するか@file@と明示します。
