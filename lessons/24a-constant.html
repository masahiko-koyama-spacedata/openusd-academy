STEP 34 · PRIMVAR INTERPOLATION

constant interpolation

Gprimがどれだけ複雑でも、値は一つだけ持ちます

今日これだけ

constantの値は常に1個で Face数やPoint数が増えても変わらない

公式情報に基づく説明

Gprim全体へ一つの値を対応させる

Primvarのinterpolationは、配列に入れた値を、Gprimのどの単位へ対応させるかを決めるMetadataです。constantを指定すると、値はGprim全体に対して一つだけになります。Meshの面を何枚に増やしても、頂点を何個に増やしても、必要な値の個数は1のままです。

OpenUSD Academy Note

Interpolationは「値をいくつ書けばよいか」を決める規則だと考えると、5種類の違いが一本の軸で並びます。constantはその軸のいちばん端、つまり「いちばん値が少ない」指定です。

USDA

2枚のFaceを持つPanelを一色にする

constant.usdaUSDA
#usda 1.0
(
    defaultPrim = "World"
    metersPerUnit = 1
    upAxis = "Y"
)

def Xform "World"
{
    def Mesh "Panel"
    {
        uniform token subdivisionScheme = "none"
        int[] faceVertexCounts = [4, 4]
        int[] faceVertexIndices = [0, 1, 4, 3, 1, 2, 5, 4]
        point3f[] points = [
            (0, 0, 0), (1, 0, 0), (2, 0, 0),
            (0, 1, 0), (1, 1, 0), (2, 1, 0),
        ]
        color3f[] primvars:displayColor = [(0.85, 0.2, 0.2)] (
            interpolation = "constant"
        )
    }
}

このPanelは、Face 2枚、Point 6個でできています。それでもprimvars:displayColorの角括弧の中に入っている値は(0.85, 0.2, 0.2)の一つだけです。interpolation = "constant"が、その一つをMesh全体へ対応させます。

Python

CreatePrimvarでinterpolationを指定する

create_constant.pyPython
from pxr import Gf, Sdf, Usd, UsdGeom

stage = Usd.Stage.CreateNew("constant.usda")
UsdGeom.Xform.Define(stage, "/World")

mesh = UsdGeom.Mesh.Define(stage, "/World/Panel")
mesh.CreateSubdivisionSchemeAttr("none")
mesh.CreateFaceVertexCountsAttr([4, 4])
mesh.CreateFaceVertexIndicesAttr([0, 1, 4, 3, 1, 2, 5, 4])
mesh.CreatePointsAttr([
    Gf.Vec3f(0, 0, 0), Gf.Vec3f(1, 0, 0), Gf.Vec3f(2, 0, 0),
    Gf.Vec3f(0, 1, 0), Gf.Vec3f(1, 1, 0), Gf.Vec3f(2, 1, 0),
])

pv = UsdGeom.PrimvarsAPI(mesh).CreatePrimvar(
    "displayColor", Sdf.ValueTypeNames.Color3fArray, UsdGeom.Tokens.constant)
pv.Set([Gf.Vec3f(0.85, 0.2, 0.2)])

stage.Save()

CreatePrimvarの3つ目の入力がinterpolationです。UsdGeom.Tokens.constantは、USDAに書く"constant"という文字列に対応する定数で、綴りの打ち間違いを防げます。pv.Setへ渡すのは、値が一つでもリストです。

Beginner notes

角括弧が二重に見える理由

OpenUSD Academy Note

USDAのcolor3f[]の[]は「この型は配列である」という意味で、型名の一部です。値の側の[ ]は配列の中身を囲む記号です。だからcolor3f[] ... = [(0.85, 0.2, 0.2)]のように、角括弧が二か所に出てきます。丸括弧( )は、色の3成分（赤・緑・青）を一つの値としてまとめる記号です。Attribute名の後ろに続く丸括弧の中は、Attribute Metadataを書く場所で、interpolationはここに入ります。

よくある間違い

「一つでいい」を忘れて値を並べる

Face数だけ値を書いてしまう

constantなのに値を2個書くと、規則と合いません。余分な値は使われないか、Rendererによっては警告になります。Face別に色を変えたいときは、STEP 35のuniformを使います。

interpolationを書き忘れる

primvars:displayColorを書いてもinterpolationを指定しないと、そのPrimvarの既定値が使われます。displayColorの場合はSchemaでconstantが既定になっていますが、意図を明示するために書くことを勧めます。

値を配列にしない

color3f[]は配列型なので、値が一つでも角括弧が必要です。= (0.85, 0.2, 0.2)とは書けません。

Glossary

このレッスンの用語

constant
Gprim全体へ値を一つだけ対応させるPrimvar Interpolation。
Interpolation（補間）
Primvarの値を、Gprimのどの単位へ対応させるかを決めるMetadata。
Gprim
MeshやSphereなど、実際に描画される形を持つPrimの総称。Geometric Primitiveの略。
Face
Meshを構成する面。faceVertexCountsの要素数がFaceの枚数になる。
Point
Meshの頂点の位置。pointsに並ぶ座標のこと。
subdivisionScheme
Meshを細分化するかどうかを決めるAttribute。noneは細分化せず、書いた多角形のまま扱う。
