LESSON 24A

constant

Gprim全体へ一つの値を使うInterpolation

今日これだけ: 一Primに一値

公式情報に基づく説明

公式: constantはGprim全体へ一値を対応させます。

Face数やPoint数が増えても一値です。

目的とDiagram

USDA

color3f[] primvars:displayColor = [(1, 0, 0)] (
    interpolation = "constant"
)

角括弧内に一値です。

Python

pv.SetInterpolation(UsdGeom.Tokens.constant)
pv.Set([Gf.Vec3f(1, 0, 0)])

USDA → Python

"constant" → Tokens.constant

例題

100 FaceのMesh全体を赤にする値数は？ 1です。

よくある間違い

原因: Face数だけ値を書く。
解決策: constantのdomainはPrim全体です。

用語集

constant
Gprim全体へ一値。
domain
値を対応させる単位。
