STEP 75 · MUTING AND SESSION

Layer MutingとSession Layer

ファイルを書き換えずに、合成を変えます

今日これだけ

MuteはLayerを一時的に無かったことにし Session Layerはファイルを汚さずに一番強い意見を置ける

公式情報に基づく説明

ファイルを書き換えずに、合成を変える2つの方法

ここまで、合成を変えるにはどこかのLayerに書く必要がありました。しかし「今だけ試したい」「保存はしたくない」ことがあります。そのための仕組みが2つあります。

Layer Mutingは、指定したLayerをその場だけ無かったことにする機能です。stage.MuteLayer(path)を呼ぶと、そのLayerの意見が合成から外れます。ファイルは1文字も変わりません。UnmuteLayer()で戻ります。重いLayerを一時的に外して確認する、ある工程の作業を切って原因を切り分ける、といった使い方をします。

Session Layerは、Stageを開くと自動で用意される保存されない一番強いLayerです。STEP 48のLayer Stackで言えば、Root Layerのさらに上に積まれます。ここへ書いた意見はすべてに勝ち、しかもファイルには残りません。ビューアの表示切り替えや、一時的な選択状態を置く場所です。

OpenUSD Academy Note

2つは向きが逆です。Mutingは引き算で、あるLayerの意見を丸ごと消します。Session Layerは足し算で、一番強い意見を上に足します。「この色はどのLayerから来ているのか」を切り分けたいならMuting、「とりあえずこう見せたい」ならSession Layerです。

このUSDAファイルを開く

Python

muteして、戻す

mute.pyPython
from pxr import Usd

stage = Usd.Stage.Open("root.usda")
path = "/Ball"

def color():
    return stage.GetPrimAtPath(path).GetAttribute("primvars:displayColor").Get()

print("muteする前:", color())
stage.MuteLayer("./look.usda")
print("muteした後:", color())
print("muted一覧 :", stage.GetMutedLayers())
stage.UnmuteLayer("./look.usda")
print("戻した後  :", color())
実行結果Output
muteする前: [(0.9, 0.2, 0.2)]
muteした後: None
muted一覧 : ['/private/tmp/ms/look.usda']
戻した後  : [(0.9, 0.2, 0.2)]

muteした瞬間に色がNoneになりました。look.usdaの意見が合成から外れ、誰もdisplayColorを書いていない状態になったためです。この間、ファイルは一度も書き換えていません。GetMutedLayers()が返すのは解決後の絶対パスです。

Python

Session Layerへ書く

session.pyPython
from pxr import Usd, UsdGeom

session = stage.GetSessionLayer()

# EditContext の間だけ、書き込み先が Session Layer になる
with Usd.EditContext(stage, session):
    UsdGeom.Imageable(stage.GetPrimAtPath("/Ball")).CreateVisibilityAttr("invisible")

print("visibility        :",
      UsdGeom.Imageable(stage.GetPrimAtPath("/Ball")).ComputeVisibility())
print("root.usdaに書かれた:", "visibility" in open("root.usda").read())
print("session側にはある  :", "visibility" in session.ExportToString())
実行結果Output
visibility        : invisible
root.usdaに書かれた: False
session側にはある  : True

合成の結果はinvisibleになっているのに、root.usdaには何も書かれていません。Usd.EditContextはSTEP 66のVariant Edit Contextと同じ仕組みで、その間だけ書き込み先を切り替えます。

Beginner notes

usdviewで見えていた一時的なLayer

OpenUSD Academy Note

STEP 111でLayer Stackを表示したとき、先頭に…-session.usdaという見覚えのないLayerが出ていました。あれがSession Layerです。ファイルとして存在せず、Stageを開くたびに新しく作られます。

だから、Session Layerに書いた内容はStageを閉じると消えます。残したいなら、stage.GetRootLayer()など保存されるLayerへ書きます。「変更したのに保存されない」と思ったら、書き込み先がSession Layerになっていないかを疑います。

よくある間違い

消えた・残らない

Session Layerに書いて保存したつもりになる

Session Layerは保存されません。Stageを閉じれば消えます。永続させたいならRoot Layerなど、ファイルを持つLayerへ書きます。

MuteしたままSaveする

Muteは合成から外すだけで、ファイルの内容は変わりません。ただし、その状態で他の編集をして保存すると、外れているLayerの意見を前提にした値を書いてしまうことがあります。切り分けが終わったらUnmuteします。

相対パスと絶対パスを取り違える

MuteLayer()には識別子を渡します。GetMutedLayers()が返すのは解決後の絶対パスなので、渡した文字列と一致するとは限りません。

Muteで消えた値を「壊れた」と読む

意見を出していたLayerを外したのだから、値がNoneになるのは正しい結果です。誰がその値を書いていたかを特定する手段として使います。

Glossary

このレッスンの用語

Layer Muting
指定したLayerを合成から一時的に外す機能。ファイルは変更されない。
MuteLayer / UnmuteLayer
Layerを外す・戻すPython API。GetMutedLayers()で現在外れているものを確認できる。
Session Layer
Stageを開くと自動で用意される、保存されない一番強いLayer。一時的な変更を置く。
Root Layer
Stageの起点となるLayer。stage.GetRootLayer()で得られ、保存される。
Usd.EditContext
その間だけ書き込み先のLayerを切り替える仕組み。Session LayerやVariantへの書き込みに使う。
