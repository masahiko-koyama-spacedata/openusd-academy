OpenUSDとは何か

ファイル形式だけではないOpenUSDの役割を、最小のStageから理解します

今日これだけ

OpenUSDは複雑な3Dシーンを記述・合成・共有するためのオープンソースのフレームワーク

公式情報に基づく説明

一つの共通言語で3Dシーンを扱う

NVIDIA Learn OpenUSDは、OpenUSDをPixarが開発した、3Dシーンの記述、合成、シミュレーション、共同作業のためのオープンソースフレームワークと説明しています。非破壊の共同作業、再利用可能な構成要素、アプリケーション間の相互運用が主要な能力です。

OpenUSD Academy Note

「完成した3Dモデルを入れる箱」だけではありません。複数の人やツールが別々に持つシーン記述を、元データを壊さず一つの見え方へ組み立てる仕組みまで含みます。

Diagram

ファイルからStageという統一された見え方へ

USDA

人が読める最小のシーン記述

overview.usdaUSDA
#usda 1.0

def Xform "World"
{
}

#usda 1.0はUSDAヘッダー、defはPrimの定義、XformはPrim型、"World"は名前です。左波括弧{から右波括弧}までがWorldの内容です。

結果

このUSDAファイルを開く

Python

同じシーン記述をAPIで作る

create_overview.pyPython
from pxr import Usd

stage = Usd.Stage.CreateNew("overview.usda")
stage.DefinePrim("/World", "Xform")
stage.Save()

fromとimportはpxrパッケージからUsdモジュールを読み込む語です。丸括弧()は関数へ渡す値を囲み、カンマ,はPathと型を分けます。ピリオド.は左側に属する機能へ進む区切り、=は右側のStageを左側の名前へ割り当てます。

USDA → Python mapping

記述と操作を対応させる

  1. USDA

    #usda 1.0↓

    Python

    Usd.Stage.CreateNew("overview.usda")

    USDAファイルをルートLayerとする新しいStageを作ります。

  2. USDA

    def Xform "World"↓

    Python

    stage.DefinePrim("/World", "Xform")

    同じ名前と型のPrimを同じPathへ定義します。

Beginner notes

記法を読み飛ばさない

OpenUSD Academy Note

インデントは階層を読みやすくし、波括弧が範囲を決めます。引用符は半角を使います。Pathの先頭の/はStageのpseudo-rootから始まる絶対Pathです。

よくある間違い

OpenUSDとUSDAを同じものだと思わない

OpenUSDは拡張子だと思う

OpenUSDはフレームワークです。USDA、USDC、USD、USDZはファイル形式です。

Stageを一つのファイルだと決めつける

Stageは複数のLayerから構成されることがあります。
