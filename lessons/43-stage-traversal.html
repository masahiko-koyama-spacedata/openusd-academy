Stage Traversal

Stage上のPrimを、上から順に一つずつ調べます

今日これだけ

Traverseは既定で「使えるPrim」だけを深さ優先で返す

公式情報に基づく説明

親を先に、子を後に返す

Stage.Traverse()は、Stage上のPrimを深さ優先の行きがけ順（親を先、子を後）で返します。既定では、定義されていてActiveで、abstractでもinstance proxyでもないPrimだけを返します。この条件のことをDefault Predicateと呼びます。条件を外してすべてのPrimを見たいときはTraverseAll()を使います。

OpenUSD Academy Note

「Traverseに出てこない＝存在しない」ではありません。STEP 31 overだけのPrim、STEP 61 Inactiveなprim、STEP 32 classは、どれも存在しているのに既定の走査からは外れます。外れる理由がそれぞれ違うことは、ここまでのレッスンで確かめたとおりです。

USDA

外れる理由を全部入れたシーン

traversal.usdaUSDA
#usda 1.0
(
    defaultPrim = "World"
    metersPerUnit = 1
    upAxis = "Y"
)

class Xform "_Style"
{
    double3 xformOp:scale = (2, 2, 2)
    uniform token[] xformOpOrder = ["xformOp:scale"]
}

def Xform "World" (
    kind = "group"
)
{
    def Xform "Robot" (
        kind = "component"
    )
    {
        def Cube "Body"
        {
            double size = 1
        }

        def Cube "Spare" (
            active = false
        )
        {
            double size = 1
        }
    }

    over "Placeholder"
    {
        double size = 1
    }

    def Xform "Styled" (
        inherits = </_Style>
    )
    {
    }
}

このシーンには、走査から外れる3つの理由がそろっています。_Styleはabstract、SpareはInactive、Placeholderはoverだけで定義されていません。

このUSDAファイルを開く

結果

TraverseとTraverseAllを見比べる

traverse.pyPython
from pxr import Usd

stage = Usd.Stage.Open("traversal.usda")

for prim in stage.Traverse():
    print(prim.GetPath())
# /World
# /World/Robot
# /World/Robot/Body
# /World/Styled

for prim in stage.TraverseAll():
    print(prim.GetPath())
# /_Style              … class なので abstract
# /World
# /World/Robot
# /World/Robot/Body
# /World/Robot/Spare   … active = false
# /World/Placeholder   … over だけで未定義
# /World/Styled

順番にも注目してください。/World/Robotのあとに、その子のBodyとSpareが来て、それから兄弟のPlaceholderへ移ります。これが深さ優先の行きがけ順です。

Diagram

走査の順番

Python

子だけを見る、途中から始める

traverse_parts.pyPython
from pxr import Usd

stage = Usd.Stage.Open("traversal.usda")
world = stage.GetPrimAtPath("/World")

# 直下の子だけを見る（既定の条件つき）
print([p.GetName() for p in world.GetChildren()])
# ['Robot', 'Styled']

# 条件を外して直下の子をすべて見る
print([p.GetName() for p in world.GetAllChildren()])
# ['Robot', 'Placeholder', 'Styled']

# 途中のPrimを起点にして、その配下だけを走査する
for prim in Usd.PrimRange(stage.GetPrimAtPath("/World/Robot")):
    print(prim.GetPath())
# /World/Robot
# /World/Robot/Body

GetChildren()は直下の子だけを返し、孫までは降りません。全体を回るのがTraverse()、一段だけ見るのがGetChildren()、途中から回るのがUsd.PrimRangeです。Usd.PrimRangeは起点のPrim自身も含みます。

USDA → Python mapping

目的ごとの使い分け

  1. やりたいこと

    Stage全体を既定の条件で回る↓

    Python

    stage.Traverse()

  2. やりたいこと

    条件を外して全部見る↓

    Python

    stage.TraverseAll()

  3. やりたいこと

    直下の子だけ見る↓

    Python

    prim.GetChildren() / prim.GetAllChildren()

  4. やりたいこと

    途中のPrimから配下を回る↓

    Python

    Usd.PrimRange(prim)

Beginner notes

pseudo-rootは返らない

OpenUSD Academy Note

Traverse()の結果に/（pseudo-root）は含まれません。走査はその子から始まります。上の例で最初に返るのが/_Styleや/Worldなのはそのためです。/自体を取得したいときはstage.GetPseudoRoot()を使います。

よくある間違い

走査中に構造を変える

回しながらPrimを追加・削除する

走査中にStageの構造を変えると、結果が予測できなくなります。いったんPathを集めてから、走査の外で変更します。

GetChildrenで孫まで取れると思う

返るのは直下の子だけです。深く回るならTraverse()かUsd.PrimRangeを使います。

出てこないPrimを「無い」と判断する

まずTraverseAll()で確認します。出てくるなら、外れている理由（abstract・Inactive・未定義）を調べます。

順番を気にせず処理する

親が先に返るので、親の情報を使って子を処理する書き方が自然に書けます。逆に子から集計したい場合は、いったんリストに貯めてから逆順に回します。

Glossary

このレッスンの用語

Traversal（走査）
Stage上のPrimを順に訪れること。
深さ優先・行きがけ順
親を先に返し、子へ降りきってから兄弟へ移る訪問順。
Default Predicate
Traverse()が既定で使う条件。定義済み・Active・非abstract・非instance proxy。
Usd.PrimRange
任意のPrimを起点に、その配下を走査するPythonのオブジェクト。
GetChildren / GetAllChildren
直下の子を返すPython API。後者は条件を外す。
pseudo-root
Stage階層の出発点/。走査の結果には含まれない。
