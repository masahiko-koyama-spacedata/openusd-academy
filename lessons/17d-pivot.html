Pivot

回転と拡縮の中心を原点以外へ移すための位置

今日これだけ

Pivotは中心へ移し、変換後に元へ戻す

回転・拡縮の前後を対になるtranslateで挟み、ドアの蝶番や車輪の軸を中心にします。

公式情報に基づく説明

ScaleとRotateが共有する中心

公式: XformCommonAPIはtranslation、rotation、scaleと、scale-rotate pivotを扱います。SetPivot()は指定時刻のpivot位置を設定します。

公式: UsdGeomXformableは同じpivot値を正方向と逆方向で対にして使えます。逆操作はxformOpOrder内の!invert! prefixで表し、別の逆値Attributeを重複してauthorしません。

OpenUSD Academy Note

PivotはGeometryの点を移動しません。変換を計算するときだけ、一時的に中心を原点へ合わせる仕組みです。

なんのためにあるのか

物体らしい回転中心を作る

中心原点のドアをそのまま回すと中央で回ります。蝶番の位置をpivotにすれば端を中心に開きます。同じ考え方で車輪の軸、Robotの関節、蓋の付け根を表せます。

Diagram

三段階で中心を変える

USDA

蝶番を中心にドアを回す

pivot.usdaUSDA
#usda 1.0

def Xform "Door" {
    float3 xformOp:rotateXYZ = (0, 60, 0)
    float3 xformOp:translate:pivot = (-1, 0, 0)
    uniform token[] xformOpOrder = [
        "xformOp:translate:pivot",
        "xformOp:rotateXYZ",
        "!invert!xformOp:translate:pivot"
    ]
}

pivotはtranslate操作へ付けたsuffixです。二つ目のコロンもnamespace区切りです。!invert!は対になる操作を逆変換として評価する特別なprefixで、独立したAttribute名ではありません。

記号を読む

!invert!まで一つずつ読む

  1. xformOp:translate:pivot

    pivot用と識別できるsuffix付きtranslate操作です。

  2. (-1, 0, 0)

    回転・拡縮の中心として使う三成分値です。

  3. !invert!

    対応する操作の逆変換を使う特別なprefixです。

  4. xformOpOrder

    pivot、rotate、inverse pivotを変換stackへ並べます。

Python

XformCommonAPIでpivotを書く

create_pivot.pyPython
from pxr import Gf, Usd, UsdGeom

stage = Usd.Stage.CreateNew("pivot.usda")
door = UsdGeom.Xform.Define(stage, "/Door")
api = UsdGeom.XformCommonAPI(door)

api.SetPivot(Gf.Vec3f(-1.0, 0.0, 0.0))
api.SetRotate((0.0, 60.0, 0.0))
stage.Save()

SetPivot()はGf.Vec3fの位置を受け取ります。SetRotate()の既定Rotation OrderはXYZです。明示したい場合は第2引数へ指定します。

USDA → Python mapping

対の操作をAPIへ対応させる

  1. USDA

    xformOp:translate:pivot = (-1, 0, 0)↓

    Python

    api.SetPivot(Gf.Vec3f(-1, 0, 0))

  2. USDA

    !invert!xformOp:translate:pivot

    XformCommonAPIがpivotの逆操作を共通構成へ含めます。

例題

必要な中心を選ぶ

問題1 ドアが中央で回ってしまう

答え: 蝶番位置をpivotにします。Geometryの原点を作り直さず回転中心を変更できます。

問題2 車輪を軸の周りに回したい

答え: 軸位置をpivotにし、適切な軸のRotateを組み合わせます。

問題3 物体全体を別の場所へ移したい

答え: Pivotではなく通常のTranslateを使います。Pivotは最終配置ではなく変換中心です。

よくある間違い

Pivotを通常の移動と混同しない

inverse用の値を別Attributeへ手書きする

原因: 正負の値を二重管理しようとしています。

解決策: !invert! tokenで同じ操作の逆変換を参照します。

Pivotだけで物体が移動すると思う

原因: 変換中心と最終配置を混同しています。

解決策: 対のpivot操作は前後で打ち消し合います。RotateまたはScaleと組み合わせて効果が現れます。

操作順を変えても同じだと思う

原因: pivot・rotate・inverse pivotの対を無視しています。

解決策: xformOpOrderで三者の並びを確認します。

Glossary

このページで出た言葉

Pivot
回転と拡縮の中心として使う位置。
inverse operation
元の変換を打ち消す逆変換。
suffix
同じ種類のxformOpを用途別に識別する追加名。
transform stack
xformOpOrderに従って操作を積み重ねる評価の考え方。
