USDA

記述を読む

root.usdaUSDA
#usda 1.0
(
    subLayers = [@./arrange.usda@]

over "World" {
    over "Ball" {
        double radius = 5
    }
}

#usda 1.0はUSDAヘッダーです。引用符は名前や文字列、波括弧はPrim内容、丸括弧はMetadata、/はPrim Pathの階層を表します。インデントは所属を読みやすくするためにそろえます。

結果

どのOpinionが見えるか

root layerのLocal Opinion 5が、sublayerのLocal Opinion 2より強いため結果は5。どちらもLIVERPSではLです。

例題

用途を判断する

問題: arrange.usdaをrootへ積み、同じ/World/Ball.radiusの2を5で上書きする

答え: SublayerをLocalとして読む。同じPathを保った作業分担。model、look、animation、shot fixを一つのLayer Stackへ積む。

公式の論点を残す

Layer Stackの内側にも順序がある

公式: Layer Stackはroot layerと、そこから再帰的に集められたsublayerの順序付き集合です。root layerが最も強く、subLayers配列では上にあるLayerが下のLayerより強くなります。sublayerのsublayerも深さ優先で収集されます。

公式: PythonではSdf.Layer.subLayerPathsをリストとして扱います。SublayerはLayer全体を同じnamespaceへ重ねるため、同じLayerを複数回積んでも別Pathの複製にはなりません。

OpenUSD Academy Note

試験では「SublayerはLIVERPSのS」という誤答に注意します。SはSpecializesです。Sublayer内に直接書いたOpinionは、そのLayer StackのL（Local）として比較されます。

よくある間違い

Sublayerを何度も積めば複製できる

誤解

原因: Arcの役割と強度順序を混同しています。

解決策: 同じnamespaceが再合成されるだけです。別Pathへ複製するならReferenceを使います。
