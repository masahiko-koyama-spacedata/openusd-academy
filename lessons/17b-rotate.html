STEP 17 · TRANSFORMS

Rotate

Primの向きを軸と角度で変える変換操作

今日これだけ

Rotateは角度だけでなく軸の適用順序も読む

rotateXYZのXYZは三つの値の並びだけでなく、回転操作を適用する順序を表します。

公式情報に基づく説明

向きを変えて子へ伝える

公式: Xformはtranslation・rotation・scaleを保持でき、親Xformの変換は子Primへ階層的に作用します。XformCommonAPIは単一のrotationとRotation Orderを共通構成でauthor・retrieveします。

公式: UsdGeomXformableでは任意のxformOp列を扱えます。複数の回転や異なる順序が必要な場合は、どの操作がどの順で評価されるかをxformOpOrderで追います。

OpenUSD Academy Note

角度が同じでもRotation Orderが違えば最終的な向きは変わり得ます。「X・Y・Zの角度」と「回す順番」を一組で読みます。

なんのためにあるのか

Geometryを書き換えず向きを変える

ドアを開く、車輪を回す、Lightの照射方向を変える、Robotの関節から先をまとめて回すために使います。親へRotateを書くと子孫も一緒に回るため、関節や可動部を階層で表せます。

Diagram

Y軸の周りに90度回す

USDA

Y軸へ45度回転する

rotate.usdaUSDA
#usda 1.0

def Xform "World" {
    def Cube "Box" {
        float3 xformOp:rotateXYZ = (0, 45, 0)
        uniform token[] xformOpOrder = [
            "xformOp:rotateXYZ"
        ]
    }
}

float3は三つのfloat値を持つ型です。値はX・Y・Z各軸の角度をdegreeで表します。rotateXYZのsuffixはRotation Orderです。引用符で囲んだ操作名をxformOpOrderへ入れて評価に参加させます。

記号を読む

float3 xformOp:rotateXYZ = (0, 45, 0)を分解する

  1. float3

    X・Y・Zの角度を保持する三成分型です。

  2. xformOp:rotateXYZ

    XYZ Rotation Orderの回転操作です。コロンはnamespaceの区切りです。

  3. (0, 45, 0)

    Xへ0度、Yへ45度、Zへ0度を指定します。

  4. ["xformOp:rotateXYZ"]

    角括弧はtoken配列で、評価する操作名を列挙します。

Python

Rotation Orderを明示する

create_rotate.pyPython
from pxr import Usd, UsdGeom

stage = Usd.Stage.CreateNew("rotate.usda")
box = UsdGeom.Cube.Define(stage, "/World/Box")
api = UsdGeom.XformCommonAPI(box)

api.SetRotate(
    (0.0, 45.0, 0.0),
    UsdGeom.XformCommonAPI.RotationOrderXYZ
)
stage.Save()

SetRotate()の第1引数は三つの角度、第2引数はRotation Orderです。丸括弧内の引数はカンマで区切ります。長い呼び出しは括弧内で改行し、対応する行を字下げすると読みやすくなります。

USDA → Python mapping

回転値と順序を対応させる

  1. USDA

    xformOp:rotateXYZ = (0, 45, 0)↓

    Python

    SetRotate((0, 45, 0), RotationOrderXYZ)

  2. USDA

    xformOpOrder = ["xformOp:rotateXYZ"]↓

    XformCommonAPIが共通構成の操作順をauthorします。

例題

回転値を読む

問題1 (90, 0, 0)はどの軸か

答え: X軸まわり90度です。成分はX・Y・Zの順です。

問題2 ドアを蝶番から回したい

答え: Rotateに加え、回転中心となる階層またはpivotが必要です。pivotはSTEP 23で扱います。

問題3 Robotの腕全体を回したい

答え: 腕のrootとなる親XformへRotateを書きます。階層変換が子部品へ届くためです。

よくある間違い

角度だけを見ない

XYZを値のラベルだけだと思う

原因: Rotation Orderを見落としています。

解決策: rotateXYZとrotateZYXは別の操作です。角度とorderを一緒に確認します。

radianで書く

原因: 数学APIの角度単位と混同しています。

解決策: ここで扱うrotate xformOpの角度はdegreeで読み書きします。

xformOpOrderへ名前を入れない

原因: Attributeが存在すれば評価されると思っています。

解決策: 操作名をxformOpOrderへ含めます。

Glossary

このページで出た言葉

Rotate
軸の周りにPrimの向きを変える変換操作。
Rotation Order
複数軸の回転を適用する順序。
degree
一周を360とする角度単位。
radian
円弧長を基準にした角度単位。このページのrotate値には使わない。
