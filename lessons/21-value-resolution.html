STEP 43 · PROPERTY VALUES

Value Resolution

Compositionで集めたOpinionから、問い合わせ時の最終値を決める処理

今日これだけ

Compositionは候補を集め、Value Resolutionは値を答える

Primの構成元を決める処理と、Attribute・Relationship・Metadataの最終結果を求める処理を分けます。

公式情報に基づく説明

データ型ごとの規則で解決する

公式: CompositionはPrim単位のsourceと強度順をindex化してcacheします。Value ResolutionはPropertyやMetadataを問い合わせるとき、そのindexを使って最終結果を求め、通常は値自体を事前計算しません。

公式: 多くのMetadataは最も強いOpinionが勝ちますが、dictionaryはkeyごとにcombineします。Relationshipはlist editingでtargetをcombineします。AttributeはValue Clips、Time Samples、Default Valueなどのsourceを調べます。

OpenUSD Academy Note

「強いLayerの行を一つ選ぶ」だけではありません。何を解決するかによって規則が変わるのがこのページの中心です。

なんのためにあるのか

元データを壊さず最終結果を得る

Assetの既定値、Animation、Shot固有のoverrideを別Layerに保ったまま、利用者はGet()で現在の結果を取得できます。弱いOpinionは消えず、強いOpinionを外すと再び結果へ現れます。

Diagram

二段階で最終値へ進む

USDA

強いLayerのAttribute値を見る

base.usdaUSDA
#usda 1.0
def Sphere "Ball" {
    double radius = 1
}
shot.usdaUSDA
#usda 1.0
(
    subLayers = [@./base.usda@]
)
over "Ball" {
    double radius = 3
}

subLayersはLayer配列、@ @はAsset Pathです。overは既存PrimへOpinionを追加し、強いroot Layerのradius = 3がDefault Timeの結果になります。

三種類の解決

同じ規則だと思わない

  1. Metadata

    多くは最強Opinion。dictionaryはkey単位でcombineする例外があります。

  2. Relationship

    複数targetをlist editing semanticsでcombineします。

  3. Attribute

    Value Clips、Time Samples、Default Valueを時刻と強度に基づいて調べます。Time Sample自体はSTEP 33を参照します。

Python

Default Timeと数値Timeを分ける

inspect_value.pyPython
from pxr import Usd

stage = Usd.Stage.Open("shot.usda")
radius = stage.GetPrimAtPath("/Ball").GetAttribute("radius")

print(radius.Get())
print(radius.Get(Usd.TimeCode.Default()))

引数なしのGet()はDefault Timeを使い、この例では両方とも3.0です。Animationを調べる場合は数値Time CodeやEarliestTime()を明示します。

USDA → Python mapping

Opinionとqueryを対応させる

  1. double radius = 3↓radius.Get() # 3.0
  2. /Ball.radius↓GetPrimAtPath("/Ball").GetAttribute("radius")

例題

どの処理か判断する

Reference先からPrimが現れる

答え: Compositionの仕事です。

複数Opinionからradiusが3になる

答え: Composition Indexを使ったAttributeのValue Resolutionです。

Relationship targetが複数Layerから集まる

答え: RelationshipのValue Resolutionでlist editingを適用します。

よくある間違い

何でも最強Opinion一つだと思わない

dictionary全体が置換されると思う

原因: Metadataの例外規則を見落としています。

解決策: dictionaryはkeyごとに解決されます。

RelationshipをAttributeと同じに扱う

原因: target listのcombineを無視しています。

解決策: Relationshipはlist opを追います。

Animationで引数なしGetを使う

原因: Default Timeと数値Timeを混同しています。

解決策: 調べたいTime Codeを明示します。

Glossary
