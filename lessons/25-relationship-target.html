LESSON 25 · PROPERTIES

RelationshipのTarget

一つの対象と複数の対象を、同じ仕組みで書き分けます

今日これだけ

Targetは常に一覧であり 一つでも複数でも同じRelationshipに書ける

公式情報に基づく説明

Relationshipは対象のPathを保存する

Relationshipは、ほかのScene要素を指すPath値を保存します。Targetは複数持つことができ、オブジェクトをまとめたり集めたりする用途に向いています。Targetに指定できるのはPrim Pathだけでなく、Property Pathも指定できます。PythonではGetTargetsで取得し、SetTargetsで一覧全体を設定し、AddTargetで一つ追加し、RemoveTargetで一つ削除します。

OpenUSD Academy Note

Targetは「一つ」と「複数」で別の仕組みになるのではなく、内部では常に一覧です。対象が一つのときは、要素が一つだけの一覧だと考えると、USDAの書き方の違いに迷いません。

USDA

一つなら山括弧 複数なら角括弧

targets.usdaUSDA
#usda 1.0
(
    defaultPrim = "World"
    metersPerUnit = 1
    upAxis = "Y"
)

def Xform "World"
{
    def Sphere "Ball"
    {
        double radius = 2
    }

    def Cube "Box"
    {
        double size = 2
    }

    def Scope "Selection"
    {
        custom rel primary = </World/Ball>

        custom rel members = [
            </World/Ball>,
            </World/Box>,
        ]

        custom rel driver = </World/Ball.radius>
    }
}

primaryは対象が一つなので、山括弧で囲んだPathをそのまま書きます。membersは対象が二つなので、角括弧 [ ] で一覧にし、各Pathをカンマで区切ります。driverはPrimではなくPropertyを指しており、Prim Pathの後ろにドットとProperty名を続けます。

Diagram

矢印の本数で読み分ける

Python

SetTargetsへリストを渡す

create_targets.pyPython
from pxr import Usd, UsdGeom

stage = Usd.Stage.CreateNew("targets.usda")
UsdGeom.Xform.Define(stage, "/World")
ball = UsdGeom.Sphere.Define(stage, "/World/Ball")
box = UsdGeom.Cube.Define(stage, "/World/Box")

selection = UsdGeom.Scope.Define(stage, "/World/Selection").GetPrim()

primary = selection.CreateRelationship("primary", custom=True)
primary.SetTargets([ball.GetPath()])

members = selection.CreateRelationship("members", custom=True)
members.SetTargets([ball.GetPath(), box.GetPath()])

driver = selection.CreateRelationship("driver", custom=True)
driver.SetTargets([ball.GetPath().AppendProperty("radius")])

stage.Save()

SetTargetsには、対象が一つでも角括弧のリストを渡します。ball.GetPath()は/World/BallというPathを返し、AppendProperty("radius")はその後ろにProperty名をつないで/World/Ball.radiusにします。custom=Trueは、Schemaで定義されていないPropertyであることを示します。

USDA → Python mapping

書き方を一行ずつ対応させる

  1. USDA

    custom rel primary = </World/Ball>↓

    Python

    primary.SetTargets([ball.GetPath()])

  2. USDA

    custom rel members = [</World/Ball>, </World/Box>]↓

    Python

    members.SetTargets([ball.GetPath(), box.GetPath()])

  3. USDA

    custom rel driver = </World/Ball.radius>↓

    Python

    driver.SetTargets([ball.GetPath().AppendProperty("radius")])

Beginner notes

括弧とドットを見分ける

OpenUSD Academy Note

USDAでは、山括弧 < > が一つのPathを囲み、角括弧 [ ] がPathの一覧を囲みます。一覧の最後の要素の後ろにカンマを置いても構いません。Pathの中では、スラッシュ / がPrimの親子を区切り、ドット . がPrimとPropertyを区切ります。Pythonでは、角括弧がリスト、丸括弧が関数への入力、カンマが要素の区切りです。

よくある間違い

一覧の書き方と行き先を取り違えない

複数のPathを角括弧なしで並べる

custom rel members = </World/Ball>, </World/Box>とは書けません。対象が二つ以上のときは角括弧で一覧にします。

SetTargetsとAddTargetを取り違える

SetTargetsは一覧を丸ごと置き換え、AddTargetは一つ追加します。追加したいのにSetTargetsを呼ぶと、以前のTargetが消えます。

Property Pathをスラッシュで書く

/World/Ball/radiusはPrim Pathとして読まれ、radiusという名前の子Primを指してしまいます。Propertyを指すときはドットを使い、/World/Ball.radiusと書きます。

Glossary

このレッスンの用語

Target List
Relationshipが持つTarget Pathの一覧。対象が一つのときも一覧として扱われる。
Property Path
Prim Pathの後ろにドットとProperty名を続けた、Propertyを指すPath。
SetTargets
Target Listを、渡した一覧の内容に置き換えるPython API。
AddTarget
既存のTarget Listへ、Target Pathを一つ追加するPython API。
