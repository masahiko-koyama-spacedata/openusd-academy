LESSON 01 · FOUNDATIONS

はじめてのUSDAを読む

短いテキストから、OpenUSDのシーンがどう階層として表されるかを、一文字ずつ確かめます。

初級読む時間 約20分JavaScript不要

01 · 今日これだけ

USDAではPrimを入れ子にするとシーンの階層を文字で読める

def Xform "World" は、Worldという名前のXform型Primを定義する記述です。波括弧の内側に別のPrimを書くと、そのPrimは子になります。

02 · 直感的な理解

Stageはシーン全体を見渡す窓

公式情報に基づく説明

NVIDIA Learn OpenUSDでは、Stageは合成されたシーングラフを提示するもの、PrimはOpenUSDシーンの構成要素と説明されています。Primは階層に整理され、各Primはシーングラフ内で位置を示すPathを持ちます。

OpenUSD Academy Note

このレッスンでは、Stageを「シーンの目次を開いて見るための窓」、Primを「目次に並ぶ項目」と考えます。これは理解のための比喩であり、公式用語の定義そのものではありません。

03 · USDA example

まず完成形をそのまま読む

ファイル名を lesson01.usda とします。先頭の番号は説明用であり、実際のファイルには書きません。

lesson01.usdaUSDA
1#usda 1.0
2
3def Xform "World"
4{
5    def Xform "Room"
6    {
7    }
8}

OpenUSD Academy Note

#usda 1.0 の # はこの行がファイル形式を示すヘッダーであることの一部です。usda は形式名、空白は要素の区切り、1.0 はバージョン番号です。小数点 . は1と0を区切ります。2行目は空行で、目で読みやすくするために置いています。

結果

このUSDAファイルを開く

04 · 一行ずつ読む

各行には階層を組み立てる役割がある

  1. 1

    #usda 1.0

    このテキストがUSDA形式であることを示すヘッダーです。

  2. 2

    空行

    内容はありません。人が読みやすいよう、ヘッダーとPrim定義を離しています。

  3. 3

    def Xform "World"

    def、空白、Xform、空白、二重引用符で囲んだWorldの順です。Worldという名前のXform型Primを定義します。

  4. 4

    {

    左波括弧です。3行目で始めたWorld Primの内容が、ここから始まります。

  5. 5

    def Xform "Room"

    先頭に4個の空白があります。Roomという名前のXform型Primを、Worldの内側に定義します。

  6. 6

    {

    Room Primの内容の開始です。左波括弧の前にも4個の空白があります。

  7. 7

    }

    右波括弧です。Room Primの内容がここで終わります。

  8. 8

    }

    World Primの内容がここで終わります。先頭に空白がないため、4行目の左波括弧と同じ深さだと見分けられます。

05 · Diagram

読み終えた構造を上から順に組み立てる

06–12 · 記法を分解する

見慣れない記号を全部ほどく

06

インデント

行の先頭に入れる空白です。この例では4個の空白でRoomがWorldの内側にあることを見やすくしています。

OpenUSD Academy Note

波括弧が構造を表し、インデントは人が階層を読み取る助けになります。開始と終了を同じ深さにそろえる習慣をつけましょう。

07

波括弧 { }

{は左波括弧、}は右波括弧です。左でPrimの内容を始め、対応する右で終えます。2つを合わせて一組です。

08

二重引用符 " "

半角の二重引用符でPrim名を囲みます。開始側と終了側の2つが必要です。日本語入力の曲がった引用符 “ ”とは別の文字です。

09

def

defineの短縮形です。NVIDIAの説明では、現在のLayerでPrimを定義し、そのPrimがStage上に具体的に定義されて存在することを示します。

10

Xform

Primの型です。Xformはtransformを表し、移動・回転・拡大縮小などの変換データを保持して子Primに適用できるPrimです。この例では変換値をまだ書いていません。

11

Prim名

WorldとRoomが名前です。名前は階層内のPrimを識別し、Pathの一部分になります。Xformは名前ではなく型です。

12 · PATH

/World/Room を一文字ずつ読む

/
先頭のスラッシュはStageのpseudo-rootから始まることを表します。pseudo-rootは階層の出発点です。
World
最初のPrim名です。/WorldはWorld PrimのPathです。
/
Prim名どうしを区切るスラッシュです。次の名前が子Primであることを読み取れます。
Room
Worldの子Primの名前です。全体でRoom Primの位置を一意に表します。

13 · Python

次に同じStageをPythonから作る

create_lesson01.pyPython
from pxr import Usd

stage = Usd.Stage.CreateNew("lesson01.usda")
stage.DefinePrim("/World", "Xform")
stage.DefinePrim("/World/Room", "Xform")
stage.Save()

上から順に、USDモジュールを読み込み、新しいStageを作り、Worldを定義し、その子にRoomを定義して、最後に保存します。

14 · USDA → Python mapping

直前のPythonをUSDAへ一つずつ戻す

  1. USDA

    #usda 1.0↓

    Python

    CreateNew("lesson01.usda")

    `.usda`の新しいStageを作ると、保存されるテキストにUSDAヘッダーが含まれます。

  2. USDA

    def Xform "World"↓

    Python

    DefinePrim("/World", "Xform")

    Path /World にXform型Primを定義します。

  3. USDA

    def Xform "Room"↓

    Python

    DefinePrim("/World/Room", "Xform")

    Pathに親のWorldも書き、Roomをその子として定義します。

  4. USDA

    ファイル全体↓

    Python

    stage.Save()

    Stageへの編集を保存します。

OpenUSD Academy Note

Pythonの . は、左側のオブジェクトや型に属する機能へ進む区切りとして読めます。() は丸括弧で、機能に渡す情報を内側に書きます。, はカンマで、PathとPrim型という2つの情報を分けます。= は右側で作ったStageを左側の名前stageに割り当てます。Pythonの引用符も半角の二重引用符です。

15 · Beginner notes

最初は「形」と「位置」を分けて読む

OpenUSD Academy Note

型と名前は別

XformはPrimの型、"World"はPrimの名前です。「Xformという名前」ではありません。

OpenUSD Academy Note

空の波括弧にも意味がある

Roomの波括弧内にPropertyがなくても、Room Prim自体は定義されています。「何もないファイル」ではありません。

OpenUSD Academy Note

Stageとファイルを同一視しない

この例は1つのUSDAファイルだけで単純ですが、公式説明どおりStageは複数のLayerから合成される場合があります。Stageそのものを単なるファイル名だと覚えないでください。

16 · Common mistakes

原因から解決策を見つける

引用符が全角・曲がった形

誤: def Xform “World”

正: 半角の二重引用符で def Xform "World" と書きます。

右波括弧が1つ足りない

原因: RoomかWorldのどちらかが閉じていません。

解決策: 左波括弧2個に対して右波括弧も2個あるか、内側から順に確認します。

Pythonの子Prim Pathに親がない

誤: DefinePrim("/Room", "Xform")

原因: /Roomはpseudo-rootから始まるため、RoomがWorldの子ではなくpseudo-rootの直接の子になります。

解決策: 子までの階層を含めて "/World/Room" と書きます。

#usda 1.0をPythonコメントだと思う

原因: USDAとPythonで # の役割を同じだと考えています。

解決策: USDAファイル先頭では形式を示すヘッダーとして読みます。このレッスンのPythonコードには書きません。

17 · Glossary

このレッスンで出た言葉

OpenUSD
3Dシーンの記述、合成、シミュレーション、共同作業のためにPixarが開発したオープンソースのフレームワーク。
Stage
合成されたシーングラフを提示し、Primの階層へアクセスする中心となるもの。
Scenegraph
シーン内のPrimを親子の階層として表した構造。
Prim
OpenUSDシーンの構成要素。データ、Attribute、Relationshipを保持でき、階層に並ぶ。
Specifier / def
Primの解釈意図を示す指定子。defは現在のLayerでPrimを具体的に定義する。
Xform
移動、回転、拡大縮小などの変換データを保持し、子Primへ適用できるPrim型。
Path
シーングラフ内のPrimやPropertyの位置。Prim名をスラッシュで区切って表す。
pseudo-root
Stageの階層の出発点。Pathでは単独のスラッシュ / で表す。
USDA
人が読めるテキスト形式のOpenUSD表現。
