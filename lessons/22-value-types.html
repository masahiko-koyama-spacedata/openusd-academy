Value Type

Attributeが保持できる値の形と意味を固定する型

今日これだけ

一つのAttributeは一つの型を持つ

公式情報に基づく説明

公式: Attributeには一つの定義済みdata typeがあり、Sdf.ValueTypeNamesで表します。

OpenUSD Academy Note: 三成分でも位置はpoint3f、色はcolor3fのroleを選びます。

なんのためにあるのか

別ツールでも同じ格納形式と意味で値を交換するためです。

Diagram

USDA

double size = 2
color3f tint = (1, 0, 0)
point3f[] points = [(0, 0, 0), (1, 0, 0)]

[]はarray、丸括弧は一要素の成分です。

Python

attr = prim.CreateAttribute("academy:score", Sdf.ValueTypeNames.Double)
attr.Set(2.0)

USDA → Python

double → Sdf.ValueTypeNames.Double
