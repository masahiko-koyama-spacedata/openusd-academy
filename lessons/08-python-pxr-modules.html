Pythonとpxrモジュール

役割に合うモジュールを選びます

今日これだけ

UsdはStage操作 SdfはPathとLayer Gfは数学型 UsdGeomは幾何Schema

公式情報に基づく説明

モジュールごとに責任が違う

Usdは作成・合成・読み取りの中心、SdfはLayerやPath、Gfはグラフィックス向け数学型を提供します。UsdGeomはgeometryのSchemaモジュールです。

OpenUSD Academy Note

pxrを道具箱、その中のモジュールを用途別の引き出しとして整理します。

USDA

作りたい結果を先に見る

modules.usdaUSDA
#usda 1.0

def Xform "World"
{
    double3 xformOp:translate = (1, 2, 3)
    uniform token[] xformOpOrder = ["xformOp:translate"]
}

double3は3成分の数値、丸括弧は3値、角括弧は配列です。引用符内はtoken値です。波括弧とインデントはWorld Primの内容を示します。

Python

UsdGeomとGfを組み合わせる

create_modules.pyPython
from pxr import Usd, UsdGeom, Gf

stage = Usd.Stage.CreateNew("modules.usda")
world = UsdGeom.Xform.Define(stage, "/World")
xform = UsdGeom.XformCommonAPI(world)
xform.SetTranslate(Gf.Vec3d(1, 2, 3))
stage.Save()

fromは取得元、importは使う名前を示します。ピリオドはモジュールやオブジェクト内の機能へ進む記号です。

Beginner notes

Pythonの記号を読む

OpenUSD Academy Note

カンマはimport名や引数の区切り、引用符はファイル名とPath、丸括弧は関数への入力です。Pythonのインデントは処理の範囲を表すため、この例の先頭はそろえます。

よくある間違い

importの不足を見つける

Gfをimportしない

原因: Gf.Vec3dの名前が使えません。

解決策: import行にGfを加えます。

Sdfを常に必要だと思う

解決策: 役割に応じて必要なモジュールだけimportします。
