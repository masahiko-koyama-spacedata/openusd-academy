LESSON 07 · AUTHORING

USDAの基本構文

一つのPrim定義を左から順に読みます

今日これだけ

USDAは型・名前・波括弧・Propertyを順に読む

公式情報に基づく説明

テキストでシーン記述を書く

USDAは人が読めるUTF-8テキスト形式です。Primは階層を作り、PropertyはPrimの情報を保持します。

OpenUSD Academy Note

文章の文法と同じように、記号ごとの役割を分けると読めます。

USDA

最小のSphereを書く

syntax.usdaUSDA
#usda 1.0

def Sphere "Ball"
{
    double radius = 2
}

#usda 1.0は識別行です。defはPrimを定義するSpecifier、Sphereは型、"Ball"は名前です。doubleは値の型、radiusはAttribute名、=は右の値を指定します。

結果

このUSDAファイルを開く

Diagram

外側から内側へ読む

Python

同じ記述をAPIで作る

create_syntax.pyPython
from pxr import Usd, UsdGeom

stage = Usd.Stage.CreateNew("syntax.usda")
ball = UsdGeom.Sphere.Define(stage, "/Ball")
ball.CreateRadiusAttr(2)
stage.Save()

引用符は文字列、丸括弧は入力、カンマは入力の区切りです。Path /Ballの先頭のスラッシュはpseudo-rootから始まることを示します。

Beginner notes

空白と記号を区別する

OpenUSD Academy Note

インデントは所属を見やすくします。波括弧は内容の開始と終了、引用符は名前、スラッシュはPathの階層です。全角引用符は使いません。

よくある間違い

原因から解決策を見つける

型と名前を逆にする

誤: def Ball "Sphere"

解決策: 型を先、名前を引用符内に書きます。

波括弧が閉じない

原因: 左右の個数が一致していません。

解決策: 内側から一組ずつ確認します。
