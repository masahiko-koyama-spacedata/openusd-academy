Prim PathとProperty Path

スラッシュとピリオドの役割を分けて、対象を正確に指します

今日これだけ

Primはスラッシュで階層をたどり、PropertyはPrim Pathの後ろにピリオドで続ける

公式情報に基づく説明

PathはStage内の対象を識別する

Prim PathではPrim名をスラッシュ / で区切ります。pseudo-rootは / です。Property Pathでは、所有するPrimのPathにピリオド . とProperty名を続けます。

OpenUSD Academy Note

ファイルのフォルダに似ていますが、ここで読むのはStage内のシーングラフです。OSのファイルパスとは別物です。

USDA

階層とPropertyを読む

paths.usdaUSDA
#usda 1.0

def Xform "World"
{
    def Xform "Geometry"
    {
        def Sphere "Ball"
        {
            double radius = 2
        }
    }
}

引用符内の World、Geometry、Ball がPrim名です。波括弧とインデントが親子関係を示します。radiusはBall Primに属するPropertyです。

Diagram

PrimからPropertyまで一方向にたどる

Python

同じPathで対象を取得する

read_paths.pyPython
from pxr import Usd

stage = Usd.Stage.Open("paths.usda")
ball = stage.GetPrimAtPath("/World/Geometry/Ball")
radius = stage.GetAttributeAtPath("/World/Geometry/Ball.radius")

print(ball.GetPath())
print(radius.Get())

GetPrimAtPathにはPrim Pathを渡します。GetAttributeAtPathにはProperty Pathを渡します。PythonではPathを引用符で囲んだ文字列として書いています。

USDA → Python mapping

階層とPropertyをPathへ変換する

  1. USDA

    World → Geometry → Ball↓

    Python

    stage.GetPrimAtPath("/World/Geometry/Ball")

  2. USDA

    Ballの double radius↓

    Python

    stage.GetAttributeAtPath("/World/Geometry/Ball.radius")

Beginner notes

記号を一つずつ区別する

OpenUSD Academy Note

先頭の / はpseudo-rootから始める印です。途中の / はPrim名の区切りです。. はPrimからPropertyへ移る区切りです。Pythonの丸括弧はメソッドへの入力を囲み、引用符はPath文字列を囲みます。

よくある間違い

区切り記号を混ぜない

Propertyの前にもスラッシュを書く

/World/Geometry/Ball/radiusではなく、/World/Geometry/Ball.radiusです。

Prim Pathをピリオドから始める

絶対Prim Pathはpseudo-rootを表す / から始めます。

Pathの大文字と小文字を変える

Prim名は正確に一致させます。Ballとballを同じものとして扱わないでください。
