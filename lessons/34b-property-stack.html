GetPropertyStackは値を主張しているSpecを強い順に返す

公式情報に基づく説明

Propertyの単位で寄与を並べる

STEP 71 Prim StackがPrimの単位で寄与を並べるのに対し、GetPropertyStack()は一つのPropertyについて、値を主張しているSpecを強い順に並べます。引数にはTime Codeを渡します。先頭の要素が、STEP 60 Value Resolutionで勝つ側です。

OpenUSD Academy Note

「思っていた色にならない」という問題は、ほぼこれで解決します。Property Stackを表示すれば、どのファイルのどの行が勝っているのかが1行目に出ます。あとはそのファイルを開くだけです。推測でLayerを一つずつ開いて探す必要はありません。

USDA

2つのLayerが同じ色を主張している

specifier-base.usda（弱い側）USDA
    def Cube "Retouched"
    {
        double size = 1
        color3f[] primvars:displayColor = [(0.85, 0.2, 0.2)]
        double3 xformOp:translate = (0, 0, 0)
        uniform token[] xformOpOrder = ["xformOp:translate"]
    }
specifier-over.usda（強い側）USDA
    over "Retouched"
    {
        color3f[] primvars:displayColor = [(0.15, 0.35, 0.85)]
    }

同じprimvars:displayColorに、赤と青の2つの主張があります。合成結果は青ですが、それを確かめる方法を見ます。

このUSDAファイルを開く

結果

勝っている側が先頭に来る

property_stack.pyPython
from pxr import Usd

stage = Usd.Stage.Open("specifier-over.usda")
attr = stage.GetPrimAtPath("/World/Retouched").GetAttribute("primvars:displayColor")

for spec in attr.GetPropertyStack(Usd.TimeCode.Default()):
    print(spec.layer.GetDisplayName(), spec.path, spec.default)

# specifier-over.usda  /World/Retouched.primvars:displayColor  [(0.15, 0.35, 0.85)]
# specifier-base.usda  /World/Retouched.primvars:displayColor  [(0.85, 0.2, 0.2)]

print(attr.Get())
# [(0.15, 0.35, 0.85)]   … 先頭と一致する

先頭がspecifier-over.usdaの青で、最終値もそれと一致しています。spec.defaultは、そのLayerに書かれたdefault値です。Time Sampleがある場合はspec.GetInfo("timeSamples")のように別の入れ物に入ります。

2つのStackの使い分け

Python

調査用の小さな関数にする

who_wins.pyPython
from pxr import Usd


def who_wins(stage, prim_path, prop_name, time=Usd.TimeCode.Default()):
    """そのPropertyの値が、どのLayerから来ているかを表示する。"""
    attr = stage.GetPrimAtPath(prim_path).GetAttribute(prop_name)
    stack = attr.GetPropertyStack(time)
    if not stack:
        print("どのLayerにも記述がありません（Schemaの既定値のみ）")
        return
    for i, spec in enumerate(stack):
        mark = "勝ち" if i == 0 else "    "
        print("%s %-24s %s" % (mark, spec.layer.GetDisplayName(), spec.default))


stage = Usd.Stage.Open("specifier-over.usda")
who_wins(stage, "/World/Retouched", "primvars:displayColor")
who_wins(stage, "/World/Kept", "primvars:displayColor")

Stackが空のときは、どのLayerにも記述が無く、Schemaの既定値が使われている状態です。値が取れるのに空という場合は、たいていSTEP 40 Primvarの継承のように、そのPrim以外から来ています。

Beginner notes

Time Codeを渡す理由

OpenUSD Academy Note

PropertyはSTEP 45 Time Sampleを持てるため、時刻によって「どのLayerが勝つか」が変わることがあります。だからGetPropertyStackはTime Codeを取ります。時間変化を扱っていないならUsd.TimeCode.Default()を渡します。

よくある間違い

Stackが空なのを不具合だと思う

Schemaの既定値もStackに出ると思う

Stackに出るのは、実際にLayerへ書かれたSpecだけです。既定値は含まれません。

Time Codeを渡し忘れる

引数が必要です。時間を扱わないときもUsd.TimeCode.Default()を渡します。

先頭以外の値が使われていると思う

defaultの解決では先頭が勝ちます。2行目以降は「負けた主張」で、なぜその値にならないかを説明してくれます。

Prim Stackで値を探す

値の出どころを追うのはProperty Stackです。Prim Stackは構造を追うためのものです。

Glossary

このレッスンの用語

Property Stack
あるPropertyへ値を主張しているSpecを、強い順に並べたリスト。
Sdf.AttributeSpec
一つのLayerに書かれた、合成前のAttributeの記述を表すオブジェクト。
default（Spec）
そのLayerに書かれた、時間に依存しない値。
Usd.TimeCode.Default()
時間に依存しない値を指すTime Code。
