Layerはシーン記述を保持する一つのリソースです。root layerと再帰的に集めたsublayerがLayer Stackを作ります。Referenceは別のPrim階層を組み込み、Payloadは必要時にロードできます。Variant Setは選択肢、Inheritsは共有Opinion、Specializesは弱いfallbackを提供します。競合はLIVERPSの強度順序で解決されます。

OpenUSD Academy Note

ファイルを上書きして完成させるのではなく、複数の意見を残したまま最終結果を計算する仕組みとして捉えます。

丸括弧はMetadata、角括弧はLayer Pathの配列、@ @はAsset Pathです。波括弧はPrim内容、引用符はPrim名、インデントは所属を見やすくします。

Python

二つのArcを作る

compose.pyPython
from pxr import Usd

stage = Usd.Stage.CreateNew("shot.usda")
stage.GetRootLayer().subLayerPaths.append("./layout.usda")
chair = stage.DefinePrim("/World/Chair")
chair.GetReferences().AddReference("./chair.usda")
stage.Save()

ピリオドは機能へ進む区切り、丸括弧は入力です。引用符はファイル名とPrim Path、スラッシュはPrim階層を表します。

Chapter map

章内の概念を区別する

LayerとLayer Stack

Layerは一つの記述リソース、Layer Stackはroot layerと再帰的なsublayerの順序付き集合です。

ReferenceとPayload

どちらも別データを合成します。Payloadはロードとアンロードができます。

Variant Set

名前付き選択肢のうち選択されたVariantのOpinionだけが合成されます。

InheritsとSpecializes

Inheritsは共有Opinionに、Specializesは弱いfallbackに向きます。

LIVERPS

Local、Inherits、Variant Sets、relocates、References、Payloads、Specializesの強度順序を表します。資料ではLIVRPS表記も残っています。

Beginner notes

強いは新しいという意味ではない

OpenUSD Academy Note

「強い」は強度順序で優先されるという意味です。単純なファイル更新日時ではありません。相対Pathの./は現在のLayerを基準にします。

Common mistakes

Arcの目的を確認する

PayloadをReferenceと同じだと思う

原因: ロード制御の違いを見落としています。

解決策: 遅延ロードが必要かで選びます。

弱いOpinionが消えたと思う

原因: 強いOpinionが最終値として解決されています。

解決策: Layer StackとPrim Stackを調べます。
