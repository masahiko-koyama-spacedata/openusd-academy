Xformと
階層

親の変換が子へ届く構造を作ります

今日これだけ

親Xformの移動は子Primにも影響する

公式情報に基づく説明

Xformは子の空間を変換する

Xformは移動・回転・拡大縮小などの変換データを保持するPrim型です。親Xformの変換は子Primへ階層的に影響します。

OpenUSD Academy Note

箱ごと動かすと中の物も動くイメージです。実際には親から子へ変換が評価されます。

USDA

親を移動して子を置く

xform-hierarchy.usdaUSDA
#usda 1.0

def Xform "World"
{
    double3 xformOp:translate = (10, 0, 0)
    uniform token[] xformOpOrder = ["xformOp:translate"]
    def Sphere "Ball"
    {
    }
}

double3は3成分、丸括弧はX・Y・Zの値です。xformOpOrderは変換Opの適用順を保持します。角括弧は配列、引用符はtoken値です。

Diagram

変換が上から下へ届く

Python

XformCommonAPIで移動を設定する

create_hierarchy.pyPython
from pxr import Usd, UsdGeom, Gf

stage = Usd.Stage.CreateNew("xform-hierarchy.usda")
world = UsdGeom.Xform.Define(stage, "/World")
UsdGeom.XformCommonAPI(world).SetTranslate(Gf.Vec3d(10, 0, 0))
UsdGeom.Sphere.Define(stage, "/World/Ball")
stage.Save()

Gf.Vec3dが3成分の移動値です。Pathに/Worldを含めることでBallを子にします。

USDA → Python mapping

親子と変換を対応させる

  1. USDA

    xformOp:translate = (10, 0, 0)↓

    Python

    SetTranslate(Gf.Vec3d(10, 0, 0))

  2. USDA

    World内の def Sphere "Ball"↓

    Python

    Sphere.Define(stage, "/World/Ball")

Beginner notes

ローカルと親の影響を分ける

OpenUSD Academy Note

インデントと波括弧は親子を見やすくします。引用符はPrim名、スラッシュはPath階層です。PythonのピリオドはAPIへ進み、丸括弧は入力を囲みます。

Common mistakes

階層と順序を確認する

Ballを/Ballへ作る

原因: Worldの子ではありません。

解決策: /World/Ballと書きます。

xformOpOrderを無視する

原因: 複数変換は順序で結果が変わります。

解決策: 適用順を確認します。
