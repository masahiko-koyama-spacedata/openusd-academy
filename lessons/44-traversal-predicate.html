Traversal Predicate

走査するPrimを条件で絞ります

今日これだけ

Predicateは絞り込みではなく枝ごと切り落とす条件

公式情報に基づく説明

フラグを組み合わせて条件を作る

Traverse()には条件（Predicate）を渡せます。条件はUsd.PrimIsActiveのようなフラグで、&（かつ）、|（または）、~（否定）で組み合わせられます。用意されているフラグはPrimIsActive、PrimIsLoaded、PrimIsModel、PrimIsGroup、PrimIsAbstract、PrimIsDefined、PrimIsInstance、そしてPrimHasDefiningSpecifierとPrimHasClassSpecifierです。

OpenUSD Academy Note

ここがこのレッスンで最も大切な点です。Predicateは「条件に合わないPrimを結果から除く」のではなく、「条件に合わないPrimに出会ったら、そこから下へ降りるのをやめる」という働きをします。フィルタではなく枝刈りです。この違いを知らないと、結果が空になった理由が分かりません。

USDA

Lesson 43と同じシーンを使う

条件の効き方を見るため、走査から外れる理由をすべて含んだ同じシーンを使います。/_Styleはabstract、/Worldはkind = "group"、/World/Robotはkind = "component"、/World/Robot/SpareはInactive、/World/Placeholderはoverだけで未定義です。

このUSDAファイルを開く

結果

条件ごとの結果を並べる

predicates.pyPython
from pxr import Usd

stage = Usd.Stage.Open("traversal.usda")

def show(label, predicate):
    print(label, [str(p.GetPath()) for p in stage.Traverse(predicate)])

show("PrimIsAbstract  ", Usd.PrimIsAbstract)
# ['/_Style']

show("PrimIsModel     ", Usd.PrimIsModel)
# ['/World', '/World/Robot']

show("PrimIsGroup     ", Usd.PrimIsGroup)
# ['/World']

show("Defined & !abst ", Usd.PrimIsDefined & ~Usd.PrimIsAbstract)
# ['/World', '/World/Robot', '/World/Robot/Body',
#  '/World/Robot/Spare', '/World/Styled']

4つ目に注目してください。条件にPrimIsActiveを入れていないので、Inactiveな/World/Robot/Spareも結果に含まれます。Traverse()の既定に含まれていた条件は、自分でPredicateを渡した時点で自動では付きません。

確かめる

枝刈りだと分かる例

「Inactiveなものだけを集めたい」と考えて~Usd.PrimIsActiveを渡すと、直感に反して結果は空になります。

pruning.pyPython
from pxr import Usd

stage = Usd.Stage.Open("traversal.usda")

print([str(p.GetPath()) for p in stage.Traverse(~Usd.PrimIsActive)])
# []   … 空になる

# 理由: 走査は最上位から始まる。/_Style も /World も Active なので
#       条件に合わず、そこで枝ごと切られる。中まで降りない。

# 正しいやり方: 全部回してから、Python側で選ぶ
inactive = [p for p in stage.TraverseAll() if not p.IsActive()]
print([str(p.GetPath()) for p in inactive])
# ['/World/Robot/Spare']

Predicateは降りるかどうかを決めるものです。したがって「条件に合う少数を探す」用途には向きません。向いているのは「条件に合わない枝を丸ごと読まずに済ませる」用途で、大きなシーンを速く処理したいときに効きます。

Diagram

フィルタと枝刈りの違い

Python

使い分けの型

choose.pyPython
from pxr import Usd

stage = Usd.Stage.Open("traversal.usda")

# 1. 重い枝を読まずに済ませたい → Predicate
for prim in stage.Traverse(Usd.PrimIsLoaded):
    ...

# 2. 特定の性質を持つPrimを探したい → 全部回してPythonで判定
models = [p for p in stage.Traverse() if p.IsModel()]
cubes = [p for p in stage.Traverse() if p.GetTypeName() == "Cube"]

# 3. 何も除きたくない → PrimAllPrimsPredicate（TraverseAll と同じ）
everything = list(stage.Traverse(Usd.PrimAllPrimsPredicate))

Usd.PrimDefaultPredicateはTraverse()が既定で使う条件そのもので、これに自分の条件を&で足すのが安全な書き方です。Usd.PrimAllPrimsPredicateは何も除かない条件で、TraverseAll()と同じ結果になります。

USDA → Python mapping

条件の書き方

  1. やりたいこと

    既定の条件に自分の条件を足す↓

    Python

    stage.Traverse(Usd.PrimDefaultPredicate & Usd.PrimIsModel)

  2. やりたいこと

    何も除かない↓

    Python

    stage.Traverse(Usd.PrimAllPrimsPredicate)

  3. やりたいこと

    条件に合うPrimを探す↓

    Python

    [p for p in stage.TraverseAll() if 条件]

Beginner notes

フラグの意味を取り違えない

OpenUSD Academy Note

PrimIsModelはKindがModelに属するPrim、PrimIsGroupはそのうちgroupやassemblyにあたるPrimを指します。上の例でPrimIsModelが/Worldと/World/Robotを返し、PrimIsGroupが/Worldだけを返したのはこのためです。PrimIsDefinedはSpecifierの話、PrimIsActiveはactiveMetadataの話で、それぞれ別のレッスンで扱った内容に対応しています。

よくある間違い

Predicateをフィルタとして使う

否定の条件を渡して結果が空になる

~Usd.PrimIsActiveのような条件は、最上位で枝が切られて空になりがちです。探す目的ならTraverseAll()とPython側の判定を使います。

既定の条件が残ると思う

自分でPredicateを渡すと、既定の条件は付きません。残したいならUsd.PrimDefaultPredicate &を明示します。

型で絞ろうとしてフラグを探す

Prim型（Cubeなど）で絞るフラグはありません。GetTypeName()で判定します。

PrimIsModelとPrimIsGroupを同じだと思う

GroupはModelの一部です。componentはModelですがGroupではありません。

Glossary

このレッスンの用語

Traversal Predicate
走査で降りるかどうかを決める条件。フラグを&・|・~で組み合わせて作る。
枝刈り（pruning）
条件に合わないPrimに出会った時点で、その配下を訪れないこと。
PrimDefaultPredicate
Traverse()が既定で使う条件。
PrimAllPrimsPredicate
何も除かない条件。TraverseAll()と同じ結果になる。
PrimIsModel / PrimIsGroup
KindがModelに属するか、そのうちGroupにあたるかを判定するフラグ。
PrimIsLoaded
Payloadが読み込まれているかを判定するフラグ。
