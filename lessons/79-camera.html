STEP 24 · CAMERA

Cameraで写す範囲を決める

焦点距離とアパーチャの比が画角を決めます

今日これだけ

Cameraは焦点距離とアパーチャで画角が決まり その2つは世界の単位の10分の1で書く

公式情報に基づく説明

カメラもPrimで、階層に従って動く

このサイトの画像はすべて、USDAの中に書いたShotCamというCameraから撮っています。ここでその中身を扱います。

CameraはXformableなPrimです。つまりSTEP 17の階層と変換にそのまま従います。親を動かせばカメラも動きますし、xformOp:translateとxformOp:rotateXYZで位置と向きを決めます。カメラは-Z方向を向いているのが決まりです。何も回転しなければ、原点から-Z側を見ます。

写る範囲は焦点距離（focalLength）とアパーチャ（horizontalAperture・verticalAperture）の比で決まります。焦点距離が長いほど狭く、アパーチャが大きいほど広く写ります。

OpenUSD Academy Note

単位の扱いに癖があります。focalLengthとアパーチャはworld unitの10分の1で表します。実写のレンズをmmで語る慣習に合わせたもので、metersPerUnit = 1のシーンでは「50」と書けば50mm相当になります。一方clippingRangeは普通のworld unitです。同じPrimの中で単位が違うので、ここだけ注意します。

Python

既定値と、画角の計算を確かめる

inspect_camera.pyPython
from pxr import Gf, Usd, UsdGeom

stage = Usd.Stage.CreateNew("cam.usda")
cam = UsdGeom.Camera.Define(stage, "/Cam")

for name in ("focalLength", "horizontalAperture", "verticalAperture",
             "projection", "clippingRange", "fStop", "focusDistance"):
    attr = cam.GetPrim().GetAttribute(name)
    print("%-20s %-10s %r" % (name, attr.GetTypeName(), attr.Get()))

# 画角は焦点距離とアパーチャから決まる
print("FOV(50mm):", round(cam.GetCamera().GetFieldOfView(Gf.Camera.FOVHorizontal), 3))
cam.CreateFocalLengthAttr(85)
print("FOV(85mm):", round(cam.GetCamera().GetFieldOfView(Gf.Camera.FOVHorizontal), 3))
実行結果Output
focalLength          float      50.0
horizontalAperture   float      20.954999923706055
verticalAperture     float      15.290800094604492
projection           token      'perspective'
clippingRange        float2     Gf.Vec2f(1.0, 1000000.0)
fStop                float      0.0

FOV(50mm): 23.67

既定はfocalLength = 50、horizontalAperture = 20.955です。この組み合わせで水平画角は約23.7度になります。焦点距離を85にすると約14.1度まで狭くなりました。アパーチャを変えずに焦点距離だけ変えれば、写真の望遠・広角と同じ感覚で使えます。

USDA

このサイトのShotCamの中身

camera.usda（抜粋）USDA
def Camera "ShotCam"
{
    float focalLength = 35
    float2 clippingRange = (0.1, 200)
    double3 xformOp:translate = (0, 0.1, 15)
    uniform token[] xformOpOrder = ["xformOp:translate"]
}

3行しか書いていませんが、書かなかったhorizontalApertureなどは既定値が使われます（STEP 13のFallback Value）。focalLength = 35は広角寄りで、50より広い範囲が写ります。

clippingRange = (0.1, 200)は手前0.1より近いものと、奥200より遠いものを描かないという指定です。既定の(1, 1000000)のままだと、カメラから1未満の距離にあるものが消えます。近くを写したいのに何も出ない、というときはここを疑います。

Diagram

画角を決める3つの値

被写界深度と時間

fStopとshutterは、対応するRendererでだけ効く

Attribute既定意味
fStop0.0絞り。0は「被写界深度なし」を意味する
focusDistance0.0ピントの合う距離（world unit）
shutter:open / shutter:close0.0 / 0.0シャッターの開閉時刻。モーションブラーに使う
exposure0.0露出。2のべき乗で明るさを足す
stereoRolemonoステレオ撮影での役割

これらは対応しているRender Delegateでのみ効きます。STEP 86で見たHdStormのようなリアルタイム描画では、被写界深度やモーションブラーは無視されるか簡略化されます。値を書いたのに変化しないときは、まずRendererが対応しているかを確かめます。

Beginner notes

同じ名前のCameraを複数置かない

OpenUSD Academy Note

usdrecord --camera ShotCamのように名前だけでカメラを指定すると、同じ名前のCameraが複数あるときにどれが使われるかが決まりません。この教材でも、Asset側とシーン側の両方にShotCamがあったせいで、真っ白な画像が出たことがありました。

対策は2つです。Asset側のカメラはAssetCamのように名前を分けるか、--camera /Park/ShotCamのようにフルPathで指定するかです。

よくある間違い

写らない・画角が合わない

clippingRangeの既定のまま近くを撮る

既定は(1, 1000000)です。カメラから1未満の距離にあるものは描かれません。小さなAssetを寄りで撮ると、何も写らないことがあります。

focalLengthをworld unitだと思う

focalLengthとアパーチャはworld unitの10分の1です。metersPerUnitを変えたときの扱いを取り違えやすい部分です。

アパーチャを変えずに画角を合わせようとして混乱する

画角は焦点距離とアパーチャの比で決まります。片方だけ見ても決まりません。

fStopを書いてボケないと悩む

被写界深度に対応していないRendererでは効きません。fStop = 0は「被写界深度なし」の意味です。

カメラの向きを+Zだと思う

カメラは-Z方向を向きます。何も回転していないカメラは、原点から-Z側を見ています。

Glossary

このレッスンの用語

UsdGeomCamera
カメラを表すPrim。Xformableなので階層と変換に従う。-Z方向を向く。
focalLength（焦点距離）
レンズの焦点距離。world unitの10分の1で表す。大きいほど狭く写る。
Aperture（アパーチャ）
撮像面の大きさ。horizontalAperture・verticalAperture。world unitの10分の1で表す。
clippingRange
描画する距離の範囲。world unitで、手前と奥の2つの値を持つ。
projection
投影方法。perspective（既定）とorthographicがある。
fStop / focusDistance
被写界深度の設定。fStop = 0は被写界深度なしを意味する。
shutter:open / shutter:close
シャッターの開閉時刻。モーションブラーに使う。
