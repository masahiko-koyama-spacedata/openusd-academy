STEP 39 · PRIMVAR INTERPOLATION

Indexed Primvars

値を一度だけ書き、番号で何度でも使い回します

今日これだけ

indicesを付けると 値の配列は短くしたまま必要な個数を満たせる

公式情報に基づく説明

値の配列とindexの配列に分ける

Primvarには、値そのものを並べた配列とは別に、indicesという位置番号の配列を付けられます。indicesがあるとき、Interpolationが要求する個数を満たさなければならないのはindicesのほうで、値の配列は使う種類の数だけあれば足ります。実際に使われる値は、indicesの各要素が指す位置の値です。この形式をIndexed Primvarと呼びます。

OpenUSD Academy Note

同じ値が何度も出てくるデータほど効果があります。たとえば10万個のFace Vertexが4色しか使っていない場合、値を10万個並べる代わりに、値4個とindex 10万個で表せます。indexはただの整数なので、色や座標の配列よりずっと軽くなります。

USDA

2色を8つのFace Vertexへ割り当てる

indexed.usdaUSDA
#usda 1.0
(
    defaultPrim = "World"
    metersPerUnit = 1
    upAxis = "Y"
)

def Xform "World"
{
    def Mesh "Panel"
    {
        uniform token subdivisionScheme = "none"
        int[] faceVertexCounts = [4, 4]
        int[] faceVertexIndices = [0, 1, 4, 3, 1, 2, 5, 4]
        point3f[] points = [
            (0, 0, 0), (1, 0, 0), (2, 0, 0),
            (0, 1, 0), (1, 1, 0), (2, 1, 0),
        ]
        color3f[] primvars:displayColor = [(0.85, 0.2, 0.2), (0.15, 0.35, 0.85)] (
            interpolation = "faceVarying"
        )
        int[] primvars:displayColor:indices = [0, 0, 0, 0, 1, 1, 1, 1]
    }
}

値は赤と青の2つだけです。interpolation = "faceVarying"はFace Vertexの総数である8個を要求しますが、その8個を用意しているのはindicesのほうです。前の4つが0なので1枚目のFaceは全部赤、後の4つが1なので2枚目のFaceは全部青になります。

indexが値を指す

Python

SetIndicesで番号を与える

create_indexed.pyPython
from pxr import Gf, Sdf, Usd, UsdGeom

stage = Usd.Stage.CreateNew("indexed.usda")
UsdGeom.Xform.Define(stage, "/World")

mesh = UsdGeom.Mesh.Define(stage, "/World/Panel")
mesh.CreateSubdivisionSchemeAttr("none")
mesh.CreateFaceVertexCountsAttr([4, 4])
mesh.CreateFaceVertexIndicesAttr([0, 1, 4, 3, 1, 2, 5, 4])
mesh.CreatePointsAttr([
    Gf.Vec3f(0, 0, 0), Gf.Vec3f(1, 0, 0), Gf.Vec3f(2, 0, 0),
    Gf.Vec3f(0, 1, 0), Gf.Vec3f(1, 1, 0), Gf.Vec3f(2, 1, 0),
])

pv = UsdGeom.PrimvarsAPI(mesh).CreatePrimvar(
    "displayColor", Sdf.ValueTypeNames.Color3fArray, UsdGeom.Tokens.faceVarying)
pv.Set([Gf.Vec3f(0.85, 0.2, 0.2), Gf.Vec3f(0.15, 0.35, 0.85)])
pv.SetIndices([0, 0, 0, 0, 1, 1, 1, 1])

stage.Save()

読む側ではpv.ComputeFlattened()が便利です。これはindexを解いた後の配列、つまりこの例では8個の色を返します。pv.IsIndexed()でindexが付いているかを判定でき、pv.GetIndices()でindexの配列そのものを取得できます。

USDA → Python mapping

行ごとに対応させる

  1. USDA

    primvars:displayColor = [赤, 青]↓

    Python

    pv.Set([Gf.Vec3f(...), Gf.Vec3f(...)])

  2. USDA

    primvars:displayColor:indices = [0, 0, 0, 0, 1, 1, 1, 1]↓

    Python

    pv.SetIndices([0, 0, 0, 0, 1, 1, 1, 1])

  3. USDA

    （indexを解いた後の8個）↓

    Python

    pv.ComputeFlattened()

Beginner notes

indicesの名前の付き方

OpenUSD Academy Note

indexの配列は、元のPrimvar名の後ろに:indicesを付けた名前になります。primvars:displayColorならprimvars:displayColor:indicesです。コロン:はNamespaceの区切りで、「displayColorに属するindices」という関係を表します。型は必ずint[]で、値の配列の何番目かを0から数えて指します。

よくある間違い

どちらの配列が個数を満たすのかを取り違える

値の配列のほうを個数に合わせる

indexを付けたのに値も8個書いてしまうと、使い回しの効果がありません。個数を満たすのはindicesのほうです。

範囲外のindexを書く

値が2個しかないのに2や-1を指すと、値を取り出せません。indexは0から「値の個数 − 1」までです。

indexを解かずに値を比べる

Pythonでpv.Get()を呼ぶと、indexを解く前の短い配列が返ります。実際に使われる並びが必要なときはpv.ComputeFlattened()を使います。

Glossary

このレッスンの用語

Indexed Primvar
値の配列とindexの配列を分けて持つPrimvar。同じ値を使い回せる。
indices
値の配列の何番目を使うかを並べたint[]の配列。Primvar名の後ろに:indicesを付けて表す。
ComputeFlattened
indexを解いた後の値の並びを返すPython API。
Namespace（名前空間）
Property名をコロンで区切って階層的にまとめる仕組み。
