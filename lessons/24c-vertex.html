STEP 24 · PRIMVAR INTERPOLATION

vertex interpolation

Pointごとに値を置き、その間はなめらかにつなぎます

今日これだけ

vertexの値の個数はPointの個数と同じで Faceの内側は補間される

公式情報に基づく説明

Pointを単位として値を対応させる

vertexは、pointsに並んだ各Pointへ一つずつ値を対応させるInterpolationです。値の個数はPointの個数と一致します。Faceの内側の値は、そのFaceが使っているPointの値から、Surfaceの基底関数にしたがって補間されます。Meshが細分化されない設定なら、この補間は面上の線形補間になります。

OpenUSD Academy Note

uniformとの違いは「境目が出るかどうか」です。vertexでは、隣り合うFaceが同じPointを共有しているため、その位置では必ず同じ値になります。つまりFaceをまたいでも値が途切れません。色や法線をなめらかに変化させたいときはこれを使います。

USDA

6個のPointへ6つの色を渡す

vertex.usdaUSDA
#usda 1.0
(
    defaultPrim = "World"
    metersPerUnit = 1
    upAxis = "Y"
)

def Xform "World"
{
    def Mesh "Panel"
    {
        uniform token subdivisionScheme = "none"
        int[] faceVertexCounts = [4, 4]
        int[] faceVertexIndices = [0, 1, 4, 3, 1, 2, 5, 4]
        point3f[] points = [
            (0, 0, 0), (1, 0, 0), (2, 0, 0),
            (0, 1, 0), (1, 1, 0), (2, 1, 0),
        ]
        color3f[] primvars:displayColor = [
            (0.85, 0.2, 0.2), (0.95, 0.8, 0.15), (0.15, 0.35, 0.85),
            (0.85, 0.2, 0.2), (0.2, 0.7, 0.3), (0.15, 0.35, 0.85),
        ] (
            interpolation = "vertex"
        )
    }
}

pointsが6個なので、色も6個です。並び順はpointsとまったく同じで、1つ目の色が1つ目のPointの色になります。下の行の3点が赤・黄・青、上の行の3点が赤・緑・青です。

Python

pointsと同じ順番で値を並べる

create_vertex.pyPython
from pxr import Gf, Sdf, Usd, UsdGeom

stage = Usd.Stage.CreateNew("vertex.usda")
UsdGeom.Xform.Define(stage, "/World")

mesh = UsdGeom.Mesh.Define(stage, "/World/Panel")
mesh.CreateSubdivisionSchemeAttr("none")
mesh.CreateFaceVertexCountsAttr([4, 4])
mesh.CreateFaceVertexIndicesAttr([0, 1, 4, 3, 1, 2, 5, 4])
mesh.CreatePointsAttr([
    Gf.Vec3f(0, 0, 0), Gf.Vec3f(1, 0, 0), Gf.Vec3f(2, 0, 0),
    Gf.Vec3f(0, 1, 0), Gf.Vec3f(1, 1, 0), Gf.Vec3f(2, 1, 0),
])

pv = UsdGeom.PrimvarsAPI(mesh).CreatePrimvar(
    "displayColor", Sdf.ValueTypeNames.Color3fArray, UsdGeom.Tokens.vertex)
pv.Set([
    Gf.Vec3f(0.85, 0.2, 0.2), Gf.Vec3f(0.95, 0.8, 0.15), Gf.Vec3f(0.15, 0.35, 0.85),
    Gf.Vec3f(0.85, 0.2, 0.2), Gf.Vec3f(0.2, 0.7, 0.3), Gf.Vec3f(0.15, 0.35, 0.85),
])

stage.Save()

色のリストとpointsのリストは、必ず同じ長さ・同じ順番にします。len(mesh.GetPointsAttr().Get())で個数を確認できます。

Beginner notes

PointとFace Vertexは別物

OpenUSD Academy Note

Pointは「空間上の頂点そのもの」で、このPanelには6個あります。Face Vertexは「Faceが頂点を使った回数」で、faceVertexIndicesの長さと同じ8個あります。中央の2つのPointはどちらも2枚のFaceから使われるので、6個のPointが合計8回使われている計算です。vertexが数えるのはPointの6個です。

よくある間違い

個数と順番でつまずく

Face Vertexの数だけ値を書く

8個書くと個数が合いません。8個必要なのはSTEP 26 faceVaryingです。

pointsと並び順を変えてしまう

値は位置番号で対応するため、pointsの並びを後から変えると色の割り当てもずれます。両方を同時に直します。

Faceごとに色を分けようとする

vertexではPointを共有する場所で必ず色がつながるため、Faceの境目で色を切り替えることはできません。それが必要なときはSTEP 26 faceVaryingを使います。

Glossary

このレッスンの用語

vertex（interpolation）
Pointごとに一つの値を対応させ、Faceの内側をSurfaceの基底関数で補間するPrimvar Interpolation。
Face Vertex
あるFaceが使う頂点の一つ分。同じPointが複数のFaceから使われると、その回数だけFace Vertexが増える。
基底関数（basis function）
Surface上の位置から値を求めるための重み付けの規則。
