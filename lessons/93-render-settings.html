STEP 93 · RENDER SETTINGS

UsdRenderで条件を書く

何を、どこへ、どう出力するか

今日これだけ

UsdRenderは「何をどう出力するか」をシーンの中に書く仕組みで Settings・Product・Varの3層

公式情報に基づく説明

描画の条件も、シーンの一部にする

STEP 92で、Stageの内容がHydraを通って描画されることを見ました。では「解像度は」「どのカメラで」「どのファイルへ」といった描画の条件はどこに書くのでしょうか。コマンドラインの引数で毎回渡すこともできますが、それでは条件が再現できません。

UsdRenderは、この条件をシーンの中にPrimとして書く仕組みです。3階層になっています。

Prim役割主な内容
RenderSettings全体の条件camera・resolution・products
RenderProduct出力ファイル1つproductName（ファイル名）・orderedVars
RenderVar出力する成分1つsourceName・dataType

RenderVarが耳慣れない言葉かもしれません。最終画像のほかに、深度や法線、マテリアルIDといった別々の成分を同時に出したいことがあります。その1つ1つがRenderVarです。合成作業ではこれらを組み合わせて調整します。

OpenUSD Academy Note

Stage MetadataのrenderSettingsPrimPathに「既定で使うRenderSettings」を書いておけます。こうすると、ツール側はファイルを開くだけで条件が分かります。STEP 61のdefaultPrimが「どのPrimが入口か」を示すのと同じ考え方です。

USDA

3層をそのまま書く

render.usdaUSDA
#usda 1.0
(
    metersPerUnit = 1
    renderSettingsPrimPath = "/Render/Settings"
    upAxis = "Y"
)

def Xform "World"
{
    def Camera "ShotCam"
    {
    }
}

def Scope "Render"
{
    def RenderSettings "Settings"
    {
        rel camera = </World/ShotCam>
        rel products = </Render/Settings/Products/beauty>
        uniform int2 resolution = (1920, 1080)

        def Scope "Products"
        {
            def RenderProduct "beauty"
            {
                rel orderedVars = </Render/Vars/color>
                token productName = "beauty.exr"
            }
        }
    }

    def Scope "Vars"
    {
        def RenderVar "color"
        {
            uniform token dataType = "color3f"
            uniform string sourceName = "Ci"
        }
    }
}

つながり方はすべてRelationshipです。rel cameraがどのCameraで撮るか、rel productsがどのファイルを出すか、rel orderedVarsがその中にどの成分を入れるかを指しています。< >で囲まれているのがPathです。

sourceName = "Ci"はRenderer側での成分の名前です。Ciは最終的な色を表す慣習的な名前で、深度ならzのようになります。どの名前が使えるかはRendererによります。

このUSDAファイルを開く

Python

既定値と、組み立て方

render_settings.pyPython
from pxr import Gf, Usd, UsdGeom, UsdRender

stage = Usd.Stage.CreateNew("render.usda")
UsdGeom.Camera.Define(stage, "/World/ShotCam")

settings = UsdRender.Settings.Define(stage, "/Render/Settings")
settings.CreateCameraRel().SetTargets(["/World/ShotCam"])
settings.CreateResolutionAttr(Gf.Vec2i(1920, 1080))

product = UsdRender.Product.Define(stage, "/Render/Settings/Products/beauty")
product.CreateProductNameAttr("beauty.exr")

var = UsdRender.Var.Define(stage, "/Render/Vars/color")
var.CreateSourceNameAttr("Ci")
var.CreateDataTypeAttr("color3f")

product.CreateOrderedVarsRel().SetTargets(["/Render/Vars/color"])
settings.CreateProductsRel().SetTargets([product.GetPath()])
stage.SetMetadata("renderSettingsPrimPath", "/Render/Settings")

for name in ("resolution", "pixelAspectRatio", "aspectRatioConformPolicy",
             "dataWindowNDC", "instantaneousShutter", "disableMotionBlur"):
    attr = settings.GetPrim().GetAttribute(name)
    print("%-26s %-8s %r" % (name, attr.GetTypeName(), attr.Get()))
実行結果Output
resolution                 int2     Gf.Vec2i(1920, 1080)
pixelAspectRatio           float    1.0
aspectRatioConformPolicy   token    'expandAperture'
dataWindowNDC              float4   Gf.Vec4f(0.0, 0.0, 1.0, 1.0)
instantaneousShutter       bool     False
disableMotionBlur          bool     False

aspectRatioConformPolicyの既定がexpandApertureです。これは解像度の縦横比とCameraのアパーチャの比が食い違ったときの扱いを決めます。STEP 26で見たとおり画角はアパーチャで決まるので、比が合わないと「どちらに合わせるか」を決める必要があります。既定はアパーチャを広げる方向です。

dataWindowNDCは出力する範囲で、(0, 0, 1, 1)が全体です。一部だけ描き直したいときにここを狭めます。

Beginner notes

書いても、対応するツールが要る

OpenUSD Academy Note

UsdRenderは条件を記述する仕組みであって、それ自体が描画するわけではありません。書いた条件を読んで使うかどうかは、Renderer側の対応しだいです。

usdrecordには--renderSettingsPrimPathという指定があり、RenderSettingsを使って描画できます。その場合、RenderSettingsに書いた値が--imageWidthなどの引数より優先されます。引数を渡したのに効かないときは、RenderSettingsが使われていないかを確かめます。

よくある間違い

条件が効かない

RenderSettingsを書いただけで反映されると思う

読む側が対応している必要があります。usdrecordなら--renderSettingsPrimPathで指定します。

引数とRenderSettingsを併用して混乱する

RenderSettingsに書いた値のほうが優先されます。どちらか一方に寄せます。

sourceNameがどのRendererでも同じだと思う

成分の名前はRenderer依存です。Ciのような名前が通じない実装もあります。

解像度とアパーチャの比を合わせない

aspectRatioConformPolicyによって、どちらかが引き伸ばされます。意図した画角にしたいなら、比を揃えるか方針を明示します。

RenderVarを作らずにProductだけ書く

何を出力するかが決まりません。orderedVarsで少なくとも1つ指しておきます。

Glossary

このレッスンの用語

UsdRender
描画の条件をシーンの中にPrimとして記述するためのSchemaの集まり。
RenderSettings
描画全体の条件を持つPrim。カメラ・解像度・出力先を指す。
RenderProduct
出力ファイル1つを表すPrim。productNameがファイル名になる。
RenderVar
出力する成分1つを表すPrim。色・深度・法線など。sourceNameはRenderer依存。
renderSettingsPrimPath
既定で使うRenderSettingsを示すStage Metadata。
aspectRatioConformPolicy
解像度の比とアパーチャの比が食い違ったときの扱いを決める設定。既定はexpandAperture。
