Material Extraction

形に「どの見た目が結び付いているか」をたどります

今日これだけ

Materialは形とは別のPrimで、Bindingという結び付きでつながる

公式情報に基づく説明

3つのPrimと1つの結び付き

ここで初めて、見た目を扱うPrimが出てきます。登場するのは3つです。Materialは見た目のひとまとまりを表すPrim、Shaderはその中で実際の計算を担うPrim、そしてBindingは「このMeshにはこのMaterialを使う」という結び付きです。BindingはMeshからMaterialへのSTEP 06 Relationshipとして書かれます。抽出するときは、この結び付きをたどってMaterialへ行き、そこからShaderの値を読みます。

OpenUSD Academy Note

形と見た目が別のPrimに分かれているのが要点です。だからSTEP 75 Workstream Layersのとおり、形の担当と見た目の担当が別のファイルで作業できます。他の多くの形式では、色はメッシュの属性として一体になっています。この違いが、抽出のときに対応づけの手間として出てきます。

USDA

Materialは別の場所に置かれている

tile.usda（抜粋）USDA
def Xform "Tile"
{
    def Scope "Looks"
    {
        def Material "Paint"
        {
            token outputs:surface.connect = </Tile/Looks/Paint/Surface.outputs:surface>

            def Shader "Surface"
            {
                uniform token info:id = "UsdPreviewSurface"
                color3f inputs:diffuseColor = (0.85, 0.35, 0.2)
                float inputs:roughness = 0.4
                token outputs:surface
            }
        }
    }

    def Scope "Geom"
    {
        def Mesh "Panel" (
            prepend apiSchemas = ["MaterialBindingAPI"]
        )
        {
            rel material:binding = </Tile/Looks/Paint>
            ... points や faceVertexCounts ...
        }
    }
}

prepend apiSchemas = ["MaterialBindingAPI"]は、このPrimがBindingを持つと宣言する行で、Bindingを書くときに自動で付きます。読む順番は3つです。Panelのmaterial:bindingがPaintを指し、Paintのoutputs:surface.connectがSurfaceを指し、Surfaceが実際の値を持っています。relで書かれているとおり、BindingはSTEP 09 Relationshipです。

Python

結び付きをたどって値まで届く

extract_material.pyPython
from pxr import Usd, UsdGeom, UsdShade

stage = Usd.Stage.Open("tile.usda")
mesh = UsdGeom.Mesh(stage.GetPrimAtPath("/Tile/Geom/Panel"))

# 1. Meshから、結び付いているMaterialを求める
material = UsdShade.MaterialBindingAPI(mesh).ComputeBoundMaterial()[0]
print(material.GetPath())        # /Tile/Looks/Paint

# 2. MaterialからShaderをたどる
shader = material.ComputeSurfaceSource()[0]
print(shader.GetIdAttr().Get())  # UsdPreviewSurface

# 3. Shaderから値を読む
print(shader.GetInput("diffuseColor").Get())   # Gf.Vec3f(0.85..., 0.35..., 0.2...)
print(shader.GetInput("roughness").Get())      # 0.4000000059604645

ComputeBoundMaterial()はタプルを返すので、先頭を取ります。この関数は継承も考慮して結び付きを解決するため、親に付いたBindingも拾えます。ComputeSurfaceSource()も同じくタプルを返します。

Python

使う側の形にまとめる

extract.pyPython
from pxr import Usd, UsdGeom, UsdShade

WANT = ("diffuseColor", "roughness", "metallic", "opacity")


def extract_material(prim):
    """Meshに結び付いた見た目を、素朴な辞書にして返す。"""
    material = UsdShade.MaterialBindingAPI(prim).ComputeBoundMaterial()[0]
    if not material:
        return None

    shader = material.ComputeSurfaceSource()[0]
    if not shader:
        return {"name": material.GetPrim().GetName(), "shader": None}

    out = {"name": material.GetPrim().GetName(),
           "shader": shader.GetIdAttr().Get(), "inputs": {}}
    for key in WANT:
        port = shader.GetInput(key)
        if port:
            out["inputs"][key] = port.Get()
    return out


stage = Usd.Stage.Open("tile.usda")
print(extract_material(stage.GetPrimAtPath("/Tile/Geom/Panel")))
# {'name': 'Paint', 'shader': 'UsdPreviewSurface',
#  'inputs': {'diffuseColor': Gf.Vec3f(0.85..., 0.35..., 0.2...),
#             'roughness': 0.4000000059604645}}

欲しい入力の名前をあらかじめ決めておき、あるものだけ拾っています。Shaderの種類によって持っている入力が違うため、まずinfo:idを読んで、種類を確かめてから値を読むのが安全な順番です。

Beginner notes

displayColorとは別のもの

OpenUSD Academy Note

ここまでのレッスンで色を付けるのに使ってきたSTEP 24 primvars:displayColorは、簡易表示用の色です。Materialとは別の仕組みで、Materialが結び付いていればそちらが優先されます。抽出するときは両方を見て、どちらを渡すかを決めます。教材の多くの例でdisplayColorを使ってきたのは、Materialを使わずに色を見せられるからです。

よくある間違い

たどる途中で止まる

Materialを見て色を探す

値はShaderにあります。Material自体は入れ物で、接続を持っているだけです。

戻り値がタプルであることを忘れる

ComputeBoundMaterial()もComputeSurfaceSource()もタプルを返します。[0]を取ります。

Bindingが無い場合を考えない

Materialが結び付いていないMeshもあります。if not materialで確かめます。

Shaderの種類を確かめずに入力を読む

info:idが違えば、入力の名前も違います。まず種類を読みます。

Glossary

このレッスンの用語

Material
見た目のひとまとまりを表すPrim。値そのものは持たず、Shaderへの接続を持つ。
Shader
見た目の計算を担うPrim。inputs:で始まる入力に実際の値を持つ。
Material Binding
GprimからMaterialへの結び付き。material:bindingというRelationshipで書かれる。
UsdPreviewSurface
ツール間で共通して扱える、標準的なShaderの種類。
info:id
そのShaderがどの種類かを示すAttribute。
MaterialBindingAPI
Bindingを読み書きするAPI Schema。
