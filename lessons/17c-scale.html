LESSON 17C · TRANSFORMS

Scale

Primの各軸方向の大きさを倍率で変える変換操作

今日これだけ

Scaleの1は元の大きさ

(2, 1, 0.5)ならXを2倍、Yを1倍、Zを0.5倍にします。

公式情報に基づく説明

倍率を親から子へ伝える

公式: ScaleはXformが保持できる変換の一つで、親Primの階層変換は子孫へ作用します。XformCommonAPIは一般的な単一のscaleを共通構成でauthor・retrieveできます。

公式: xformOpはxformOpOrderに列挙された順序で評価されます。TranslateやRotateと組み合わせる場合、順序が結果へ影響します。

OpenUSD Academy Note

Scaleは「何単位の大きさか」ではなく「元の大きさに何倍を掛けるか」です。実寸の解釈を示すmetersPerUnitとは役割が違います。

なんのためにあるのか

形の比率や階層全体の大きさを調整する

同じAssetを大小で配置する、板を一方向だけ長くする、親Xformの下にある部品全体をまとめて拡縮するために使います。Geometryのpointsを書き換えず、配置側で倍率を変更できます。

Diagram

軸ごとに倍率を掛ける

USDA

X方向だけ2倍にする

scale.usdaUSDA
#usda 1.0

def Xform "World" {
    def Cube "WideBox" {
        float3 xformOp:scale = (2, 1, 1)
        uniform token[] xformOpOrder = [
            "xformOp:scale"
        ]
    }
}

float3はX・Y・Zの三倍率を保持します。(2, 1, 1)の1は「変更なし」です。角括弧は操作名の配列、引用符はtoken値の範囲を示します。

記号を読む

float3 xformOp:scale = (2, 1, 1)を分解する

  1. float3

    三つのfloat値を持つ型です。

  2. xformOp:scale

    scale操作のAttribute名です。

  3. (2, 1, 1)

    Xへ2倍、YとZへ1倍を掛けます。

  4. uniform token[]

    時間変化を目的としないtoken配列として操作順を保持します。

Python

XformCommonAPIで倍率を書く

create_scale.pyPython
from pxr import Usd, UsdGeom

stage = Usd.Stage.CreateNew("scale.usda")
box = UsdGeom.Cube.Define(stage, "/World/WideBox")
api = UsdGeom.XformCommonAPI(box)

api.SetScale((2.0, 1.0, 1.0))
stage.Save()

SetScale()へX・Y・Zの倍率をtupleで渡します。丸括弧は関数呼び出しとtupleの両方に使われ、内側の三値がscale値です。

USDA → Python mapping

倍率を対応させる

  1. USDA

    xformOp:scale = (2, 1, 1)↓

    Python

    api.SetScale((2, 1, 1))

  2. 意味

    Xだけを2倍にし、YとZは元の倍率を保ちます。

例題

倍率を答える

問題1 全軸を3倍にする

答え: (3, 3, 3)です。三成分が同じuniform scaleです。

問題2 Yだけ半分にする

答え: (1, 0.5, 1)です。

問題3 1メートルを表したい

答え: ScaleだけではStageの単位を定義できません。metersPerUnitを別に確認します。

よくある間違い

0と1を混同しない

変更しない軸へ0を書く

原因: Translateの「移動なし」と混同しています。

解決策: Scaleの変更なしは1です。0はその軸を0倍にします。

Scaleを実寸単位だと思う

原因: 倍率とmetersPerUnitを混同しています。

解決策: Scaleは倍率、metersPerUnitは一単位を何メートルとして解釈するかです。

親Scaleの影響を忘れる

原因: 子のlocal scaleだけを見ています。

解決策: world上の大きさには祖先の変換も作用します。
