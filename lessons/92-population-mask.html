STEP 91 · POPULATION MASK

Population Mask

必要な枝だけをStageに載せます

今日これだけ

Population Maskは 必要な枝だけをStageに載せる 開かないので速く 軽い

公式情報に基づく説明

読まない、という選択肢

大きなシーンから1つのAssetだけを調べたいことがあります。STEP 88のUnloadはPayloadの中身を開かない仕組みでしたが、Payloadになっていない部分には効きません。

Population Maskは、Stageに載せるPrimそのものを、開くときに絞り込む仕組みです。指定したPathとその子孫、および先祖だけがStageに現れます。それ以外はそもそも構成されません。

Unloadとの違いは枝が存在するかどうかです。Unloadした枝はStageに存在し、後からLoad()できます。Maskで外した枝はStageに現れず、Traverse()にも出ません。

OpenUSD Academy Note

使いどころは検査や自動処理です。数万Primのシーンから1つのAssetの値を読むだけなら、全部を構成するのは無駄です。Maskで絞れば、合成そのものが省かれるので確実に速くなります。

一方、対話的なビューアには向きません。ユーザーが別の枝を見たくなったら、Stageを開き直すことになるためです。

このUSDAファイルを開く

Python

OpenMaskedで、枝を指定して開く

population_mask.pyPython
from pxr import Usd

full = Usd.Stage.Open("city.usda")
print("全部開く   :", len(list(full.Traverse())), "Prim")

mask = Usd.StagePopulationMask(["/City/BlockB"])
part = Usd.Stage.OpenMasked("city.usda", mask)

print("Maskで開く :", len(list(part.Traverse())), "Prim")
print("中身       :", [str(p.GetPath()) for p in part.Traverse()])
print("Maskの内容 :", part.GetPopulationMask().GetPaths())
print("含まれるか :", mask.Includes("/City/BlockB/Bldg_1"),
      "/", mask.Includes("/City/BlockA/Bldg_1"))
実行結果Output
全部開く   : 13 Prim
Maskで開く : 5 Prim
中身       : ['/City', '/City/BlockB', '/City/BlockB/Bldg_0',
              '/City/BlockB/Bldg_1', '/City/BlockB/Bldg_2']
Maskの内容 : [Sdf.Path('/City/BlockB')]
含まれるか : True / False

13が5になりました。注目したいのは/Cityが含まれていることです。/City/BlockBへたどり着くには親が要るので、先祖は自動的に含まれます。ただし/City/BlockAのような兄弟は含まれません。

Includes()は、あるPathがMaskに入るかを判定します。/City/BlockB/Bldg_1はTrue、/City/BlockA/Bldg_1はFalseです。

Diagram

3つの「読まない」の違い

この4つは、どの段階で切るかが違います。Maskは合成そのものを省くので最も軽く、visibilityは合成も値もそのままで描画だけを止めます。STEP 87とSTEP 88で扱った内容が、ここで1つの並びに整理できます。

Beginner notes

Maskは開くときにしか決められない

OpenUSD Academy Note

Population MaskはStage.OpenMasked()で開くときに与えます。開いた後で範囲を広げたい場合はSetPopulationMask()で設定し直せますが、そのとき合成がやり直されます。

また、Maskはファイルには書かれません。読む側の都合であって、シーンの内容ではないからです。activeがファイルに書かれるのと対照的です。

よくある間違い

絞ったのに期待と違う

先祖が含まれるのを想定していない

指定したPathへたどり着くために、先祖は自動で含まれます。数を数えるときはこれを見込みます。

兄弟も含まれると思う

含まれません。複数の枝が要るなら、Maskに複数のPathを渡します。

Maskで外した枝をLoadしようとする

Stageに存在しないのでLoad()できません。Loadで戻せるのはUnloadした枝です。

Maskをファイルに書こうとする

読む側の設定なので、ファイルには残りません。シーンの内容として残したいならactiveです。

対話的なビューアでMaskを使う

別の枝を見たくなるたびに開き直しになります。Maskは検査や自動処理向けです。

Glossary

このレッスンの用語

Population Mask
Stageに載せるPrimを開くときに絞り込む仕組み。指定したPathとその子孫、および先祖だけが構成される。
OpenMasked
Population Maskを与えてStageを開くPython API。
StagePopulationMask
載せるPathの集合を表すオブジェクト。Includes()で判定できる。
LoadNone
Payloadを一切開かずにStageを開く指定。Maskとは切る段階が違う。
